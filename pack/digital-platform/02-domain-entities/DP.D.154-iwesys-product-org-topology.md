# DP.D.154 — Топология GitHub-орг: iwesys ≠ aisystant ≠ MimEcoSys

## Три GitHub-организации и их роль

| Организация | Тип | Назначение | Трек | Язык |
|-------------|-----|-----------|------|------|
| **iwesys** | Product org | IWE-шаблон, Pack'и, скиллы, агентские правила — то, что ставится к пользователям через `update.sh`. Артефакты-дистрибутивы, не сервисы с данными. | Product (оба трека) | — (артефакт-агностик) |
| **aisystant** | Platform org (мир) | Облачная платформа Aisystant: сервисы, хранящие данные пользователей (GKE, Нью-Йорк). Мировой контур, jurisdiction-free от России. | Трек B | Только английский (код, docstring, UI-строки, README) |
| **MimEcoSys** | Platform org (Россия) | Российский мировой контур: сервисы на VK Cloud, хранящие данные российских пользователей. | Трек A | Русский (или смешанный, не английский-only) |

**Уточнение директивой пилота 29.09.2026:** критерий юрисдикции (где хранятся данные) дополнен критерием языка — `aisystant` держит только то, что целиком на английском (мировой контур, английский по умолчанию); что угодно с русским кодом/комментариями/UI для российских пользователей не может жить в `aisystant`, даже если формально данные хранились бы вне России. Оба критерия обычно совпадают (мировой контур = английский, российский = русский) — расхождение (например, англоязычный сервис с российскими данными) разбирать отдельно, пока прецедентов не было.

## Ось тира (iwesys) ≠ Ось юрисдикции (aisystant vs MimEcoSys)

- **iwesys** — не делится по юрисдикции: IWE-дистрибутив один (платформенно-агностичный артефакт, копируется к пользователю). Нет «российского iwesys» и «мирового iwesys» — нарушение OwnerIntegrity.
- **aisystant** / **MimEcoSys** — два инстанса платформы, разные юрисдикции. Данные хранятся по юрисдикции; руководства — из мирового (canonical), российский = downstream-проекция + PD-данные.

## Применение

При проектировании нового репо: «Это артефакт (скилл, Pack, скрипт) или сервис с данными?»
- Артефакт → `iwesys`
- Сервис для мирового контура → `aisystant`
- Сервис для российского контура → `MimEcoSys`

## Тест

«Объект копируется к пользователю (как пакет) или к нему подключаются (как сервис)?»
- Копируется → `iwesys`
- Подключаются + хранит данные → `aisystant` или `MimEcoSys` по юрисдикции, сверить со вторым тестом ниже

Второй тест (язык, дополнение 29.09.2026): «Код/UI/данные целиком на английском, для мирового пользователя?» Нет (есть русский код, комментарии или русскоязычный UI) → `MimEcoSys`, даже если юрисдикция данных формально не решена.

**Первый прецедент (29.09.2026):** `mentorship-service` (карточка наставника, WP-578) — русские UI-строки и русскоязычные пользователи (наставник и участники российской программы), создан 17.09 под `aisystant` по дефолту без применения этого теста. Перенесён в `MimEcoSys` задним числом.
