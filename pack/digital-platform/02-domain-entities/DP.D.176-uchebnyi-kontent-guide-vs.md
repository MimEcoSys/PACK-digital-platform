# DP.D.176: Учебный контент (guide/) ≠ Операционный контент (panel/)

**Описание:**
В контент-системе персонального обучения два независимых типа контента с разными процессами создания и развития.

- **Учебный контент (guide/)**: неизменяемый смысл для изучения. Содержит знание, принципы, методы. Актуален независимо от текущего состояния системы. Аналог: учебник.
- **Операционный контент (panel/)**: задания, организационная информация, статистика прогресса. Меняется с изменением состояния системы. Аналог: рабочая тетрадь.

**Следствие для проектирования:**
Смешение в одну директорию guide/ делает её непригодной как учебный артефакт — пилот видит задания вместо знания. Разделение → разные директории, разные артефакты, разные процессы создания и развития.

**Тест:** «Изменится ли этот контент при смене статуса пользователя или дедлайна?» Да → panel/. Нет → guide/.
