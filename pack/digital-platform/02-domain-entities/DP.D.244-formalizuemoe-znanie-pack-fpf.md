# DP.D.244: Формализуемое знание (Pack/FPF/SPF) ≠ Личное знание носителя роли (встроено в личный опыт)

**Формализуемое знание** (Pack, FPF, SPF) — универсально: его можно описать текстом и передать любому носителю роли без потери смысла. Правило, метод, принцип работает у разных людей на одной роли.

**Личное знание носителя роли** — партикулярно: оно встроено в личную историю действий, ошибок и контекста конкретного носителя роли. Попытка «описать личное знание текстом» даёт лишь оболочку — без накопленного trail носителя она не работает.

**Почему личное знание сопротивляется формализации:** оно не существует как универсальное знание. Оно формируется только через конкретную траекторию опыта. «Передать личное знание» = передать саму траекторию, а не её описание.

**Следствие для платформы:** персональное руководство (personal guide) — это попытка приблизиться к личному знанию через накопленный trail пользователя, а не через статический Pack. Pack даёт DPF. Personal guide формирует слой личного знания.

**Тест:** «Описание этого знания работает у любого носителя той же роли?» Да → Pack/FPF/SPF. Нет → личное знание, нужен trail.
