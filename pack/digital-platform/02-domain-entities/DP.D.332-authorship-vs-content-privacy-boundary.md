# DP.D.332 — Граница приватности по содержанию, не по автору

## Различение

| | Граница по автору — отклонено | Граница по содержанию — верно |
|---|---|---|
| Критерий | Кто формально написал сообщение | Какие люди и сведения представлены в тексте |
| Третьи лица | Игнорируются, если пишет автор | Учитываются цитаты, пересказы и узнаваемые детали |
| Обезличивание | Замены имени якобы достаточно | Контекст может сохранить идентифицируемость и содержание |

## Механизм

Сообщение автора о себе может включать слова наставника, пересказ разговора или сведения о других участниках. Поэтому формальное авторство сообщения не отвечает на вопрос, чьи данные оно содержит. Простая замена имён тоже не устраняет контекст и узнаваемые обстоятельства.

## Тест различения

«Можно ли по одному полю автора определить всех субъектов данных в сообщении?» Нет — границу нужно проводить по содержанию.

## Границы

Различение применимо к сообщениям, заметкам и транскриптам. Оно не задаёт место технического фильтра согласия: это отдельная ось `DP.D.324`.
