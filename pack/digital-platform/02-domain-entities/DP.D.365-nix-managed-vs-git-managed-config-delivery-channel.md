# DP.D.365 — Канал доставки конфигурации определяется её управлением

## Различение

| Объект в исходном случае | Канал изменения | Проверка результата |
|---|---|---|
| Хуки, разрешённый путь которых ведёт в Nix store | Изменение пакета и предусмотренная пересборка/активация | Версия и содержимое активного пакета на целевом хосте |
| Обычный изменяемый файл настроек | Установленная для этого файла процедура синхронизации или развёртывания | Реальное содержимое используемого файла на целевом хосте |

Режим read-only и старое время изменения — диагностические признаки, не доказательство Nix. Канал устанавливается по разрешённому пути, пакету-владельцу и манифесту либо процедуре развёртывания. Обычный writable-файл также не доказывает автоматическую доставку из Git.

## Проверка

Для каждого затронутого пути известны источник конфигурации, действующая процедура доставки и свидетельство активации на целевой машине. Git push подтверждает публикацию в репозитории, но сам по себе не подтверждает развёртывание ни одного из каналов.

## Граница

Источник описывает два маршрута на одном хосте в WP-484 Ф206. Это историческое свидетельство; текущее состояние хоста здесь не проверялось. DP.IWE.011 описывает функциональный контракт хоста, а данное различение — доставку его конфигурации.
