# DP.D.389: Версия навыков разработчика ≠ Общая версия для других агентов

Методы IWE записаны как навыки. **Версия разработчика** хранится в папке навыков Claude Code, и правят только её. **Общая версия** — копия для других ИИ-агентов (сейчас Kimi Code и Codex), которую собирает программа сборки из версии разработчика. Это не зеркало: в общей версии заголовок сокращён до полей стандарта навыков, служебные навыки и навыки «только для Claude» пропущены, адреса программ исправлены.

| | Версия разработчика | Общая версия |
|---|---|---|
| Где хранится | папка навыков Claude Code | папки навыков других агентов (общая `.agents/skills` и папки вендоров) |
| Кто правит | автор навыка; Переводчик для ИИ-агентов добавляет требования и запасные пути | никто руками: её собирает программа |
| Что содержит | все навыки, полный заголовок IWE | только навыки класса «общий», заголовок по стандарту, требования IWE в строках поля «метаданные» (`metadata`) или в файле рядом |

**Тест.** «Этот файл появится заново, если удалить папку общей версии и запустить сборку?» Если появится, файл принадлежит общей версии, и руками его не правят. Нужную правку вносят в одно из трёх мест:
- правило, одинаковое для всех навыков (как сокращать заголовок, куда класть копию), — в программу сборки;
- решение по одному навыку (какой шаг держится на особой возможности Claude, каким запасным путём его заменить, какой у навыка класс) — Переводчик для ИИ-агентов вносит в исходный навык (DP.ROLE.129);
- содержание метода — автор навыка вносит в исходный навык.

**Ошибочная модель.** «Раз Claude не читает общую папку, держим два одинаковых набора и правим оба». Два редактируемых набора расходятся. К тому же одинаковыми их держать нельзя: проверка Codex при создании навыка и загрузка в claude.ai отказывают на полях заголовка IWE, которых нет в стандарте (исследование РП-624). Как ведут себя на этих полях загрузчики других агентов, покажет проба РП-592 Ф7.

**Когда пересматривать.** Если Claude Code начнёт читать общую папку навыков, версия разработчика может переехать туда, а папка Claude станет копией. Различение от этого не меняется, меняется только то, какая папка главная.

**Статус.** Замысел РП-592 Ф7, пробой не подтверждён: программы сборки ещё нет.
