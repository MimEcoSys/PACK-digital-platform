# BYOB (Bring Your Own Base)

## 1. Определение

**BYOB** (Bring Your Own Base) — принцип владения инфраструктурой IWE: данные и процессы среды переносимы и не зависят от одного провайдера. Среда работает на ресурсах, которые пилот может заменить (устройства, репозитории, носители), а не арендует у платформы как единого поставщика.

**Ключевое:** BYOB — не запрет облака и не самохостинг. Это **контракт переносимости**: если сервис X закроется завтра, пилот восстанавливает работу за часы, а не за месяцы.

## 2. Три признака BYOB-совместимости

| # | Признак | Тест |
|---|---|---|
| 1 | **Данные в переносимом формате** | Можно ли экспортировать всё за час в Markdown / Git / JSON / SQL? |
| 2 | **Процессы на заменяемых устройствах** | Запустится ли среда на новом ноутбуке за один день? |
| 3 | **Открытые протоколы интеграций** | Используются ли Git / HTTP+JSON / MCP / SQL, а не API одной компании? |

**Тест на нарушение BYOB:** «Если завтра провайдер X закроет аккаунт без объяснения причин — потеряю ли я данные или работу IWE?» Ответ «да» — этот участок не BYOB.

## 3. Различения

| Не путать с | Разница |
|---|---|
| **Self-hosting** | BYOB не запрещает облако. Google Drive с автоэкспортом в Git = BYOB. Локальный сервер без бэкапа = не BYOB. |
| **Open Source** | OS про код инструмента. BYOB про данные пилота. Notion закрытый, но Notion+Git-экспорт = BYOB. |
| **Локально** | BYOB про переносимость владения, не про место хранения. Облако с экспортом = BYOB. |
| **Cloud Gateway (DP.IWE.003)** | Cloud Gateway — паттерн доставки знаний к внешним AI-клиентам платформой. BYOB — принцип владения средой пилотом. |

## 4. Где живёт BYOB в IWE

- **Носитель:** Машина IWE (DP.IWE.010) — материальные ресурсы, на которых работает среда.
- **Граница действия:** Граница полномочий пилота в IWE (DP.IWE.009) — внутри этой границы BYOB достижим, снаружи — нет.
- **Реализация привычки:** Резервная копия (DP.M.123) — регулярная проверка переносимости.

## 5. Антипаттерны

- **«Облако надёжнее»** — облако защищает свою стабильность, не доступ пилота. Блокировка аккаунта = потеря данных без BYOB.
- **«Экспорт когда понадобится»** — экспорт ненастроенный заранее = ручная работа в момент кризиса.
- **«Всё в одном сервисе удобнее»** — удобство при работе превращается в зависимость при смене.
