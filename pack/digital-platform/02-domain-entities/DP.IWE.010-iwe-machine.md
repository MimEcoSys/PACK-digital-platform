# Машина IWE (DP.IWE.010)

## 1. Определение

**Машина IWE** — инфраструктурный вид интеллектуальной среды: совокупность физических и цифровых ресурсов, на которых работает IWE. Машина — материальный носитель среды, а не сама среда.

**Состав Машины:**

- **Устройства** — ноутбук, телефон, NAS, VPS — то, что у пилота под управлением.
- **Хранилища** — Git-репозитории, локальные базы данных, файловые системы под управлением пилота.
- **Pack-репозитории** — формализованные знания пилота как переносимый источник истины.
- **Резервные копии** — независимые копии критичных данных (DP.M.123).
- **Среда разработки** — IDE, CLI, MCP-серверы, агентные runtime, через которые пилот взаимодействует с IWE.

## 2. Аналогия

| | Машина IWE | IWE |
|---|---|---|
| **Что** | Носитель | Целая среда |
| **Аналогия** | Тело | Личность |
| **Состав** | Устройства, репо, носители, инструменты | Все 5 архитектурных видов: системы, описания, роли, методы, рабочие продукты |
| **Необходимое** | Да | Да |
| **Достаточное** | Нет — без знаний и ролей это просто железо | Да — Машина + знания + роли + методы = IWE |

Машина для IWE — как тело для личности: необходимое, но не достаточное. Можно иметь идеальную Машину и пустую IWE (новый ноутбук без знаний); и наоборот — мощную IWE при минимальной Машине (опытный пилот с одним ноутбуком и набором скриптов).

## 3. Различения

| Не путать с | Разница |
|---|---|
| **IWE (DP.IWE.001)** | IWE — целая среда с агентами, ролями, методами. Машина — материальная инфраструктура для неё. |
| **Контур IWE (DP.IWE.009)** | Машина — что у пилота есть. Контур — чем пилот распоряжается. У одной Машины могут быть участки внутри и снаружи контура. |
| **Local Gateway (DP.IWE.005)** | Local Gateway — конкретный программный компонент Машины для координации peer-агентов. Машина включает Gateway, но не сводится к нему. |
| **Личное оборудование** | Машина не обязана быть в собственности — арендованный VPS может быть частью Машины, если пилот распоряжается им. |

## 4. Минимальная Машина

| Компонент | Минимум | Зачем |
|---|---|---|
| Устройство | 1 ноутбук | Платформа для всего остального |
| Git-репозиторий | 1 локальный + 1 удалённый | Версионируемое хранилище и резерв |
| Pack-репозиторий | 1 (PACK-personal или аналог) | Источник истины для знаний |
| Резервная копия | Автоматическая в Git + офсайт-копия | Восстановление при отказе |
| Среда разработки | IDE с поддержкой агентов (VS Code, Cursor) | Точка входа |

Это **минимум для BYOB**: при отказе одного компонента среда восстановима за день из остальных.
