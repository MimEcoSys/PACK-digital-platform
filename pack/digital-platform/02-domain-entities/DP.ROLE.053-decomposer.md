# DP.ROLE.053 — R29 Декомпозитор

## Описание

Агентная роль, декомпозирующая деятельность на стадии с физическими артефактами на входе/выходе каждой и чеклистами приёмки.

## Вход → Выход

- **Вход:** готовый РП (≥3h, open-loop)
- **Выход:** стадии с физическими I/O + чеклист приёмки для каждой стадии

## Обязанности

1. Разбить деятельность на завершённые стадии
2. Для каждой стадии определить физический артефакт на входе и выходе
3. Сформировать чеклист приёмки (acceptance criteria)
4. Сигнализировать если у стадии нет физического артефакта («детектор разрывов»)

## Место в иерархии ролей

| Роль | Функция |
|------|---------|
| R23 Верификатор | Проверяет результат по эталону |
| Навигатор (MIM.R.007) | Сопровождает траекторию развития |
| Диагност (DP.ROLE.042) | Определяет ступень и bottleneck |
| **R29 Декомпозитор** | Декомпозирует готовый РП до стадий с физическими артефактами, выявляет разрывы |

## Надсистема

Экзокортекс (DP.ARCH.001)

## Исполнитель

Скилл `/decompose`

## Триггер

РП ≥3h (open-loop work product) при открытии протоколом ОРЗ.
