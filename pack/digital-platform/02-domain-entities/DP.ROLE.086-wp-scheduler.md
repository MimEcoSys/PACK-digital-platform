# Диспетчер отложенного запуска РП / WP Scheduler (DP.ROLE.086)

<!-- see DP.SC.192, WP-487 -->

> **Kind:** Функциональная роль (FPF A.2) — полностью детерминированная программа (bash + launchd). LLM не используется: диспетчер только ставит будильники и запускает агентов, решений о содержании РП не принимает.
> **Owner Role:** Пилот (владелец очереди); техническая поддержка — R6 Кодировщик.

## 1. Миссия

Быть единственным каналом отложенного автозапуска РП: пилот произносит «запусти WP-NNN во столько-то» — диспетчер гарантирует старт вовремя, в рамках предохранителя ресурсов, с отчётом. Альтернатива — ручной запуск или cron без пробуждения и без guard'ов.

## 2. Обязанности

1. Принять задание (время, WP, агент, лимиты) и создать одноразовую задачу launchd.
2. В момент старта: session-guard open → preflight → headless-запуск агента → session-guard close.
3. Применить предохранитель: wall-clock таймаут (default 50 мин) + max-turns (claude).
4. Зафиксировать результат (done/failed/timeout) в логе и утреннем отчёте.
5. Убрать за собой: выгрузить и удалить одноразовую задачу launchd.

## 3. Полномочия

- Создавать/удалять plist в `~/Library/LaunchAgents/ai.iwe.wp-queue.*` (только свой префикс).
- Запускать kimi/claude в yolo/skip-permissions режиме внутри таймаута.
- Писать в `.iwe-runtime/wp-queue/` и `.iwe-runtime/logs/wp-queue/`.
- НЕ принимает решений по содержанию РП; НЕ меняет WeekPlan/реестр.

## 4. Связи

- `DP.SC.192` — обещание, которое роль реализует.
- `session-guard.sh` (WP-464) — открытие/закрытие сессии, семафоры.
- `kimi-standalone-preflight.sh` — проверка готовности kimi-сессии.
- kimi-peer-adapter.sh — переиспользован паттерн OAuth-refresh lockf (сериализация kimi).

## 5. Входы/выходы (артефакты)

| Вход | Выход |
|------|-------|
| `add <время> <WP> <agent> [лимиты]` | запись в `.iwe-runtime/wp-queue/queue.tsv` + plist launchd |
| срабатывание launchd | лог прогона + строка в `report.md` + статус в queue.tsv |

## 6. Режим отказа

См. DP.SC.192 «Режим отказа»: падение → статус + продолжение очереди; Мак выключен → `missed`; гонка OAuth kimi → lockf-сериализация.
