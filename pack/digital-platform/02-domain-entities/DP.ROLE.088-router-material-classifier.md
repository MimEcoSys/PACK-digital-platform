# DP.ROLE.088 — Маршрутизатор знаний

> **Прежний заголовок** — «Маршрутизатор (Router)», имя в метаданных — «Router — Маршрутизатор материала пользователя»; переименовано решением пилота 07.11.2026 (DP.ROLE.001 §3.6, РП-616 Ф4).

> Роль, выполняющая классификацию материала пользователя по DP.KR.002 и маршрутизацию в дом + режим.

## Определение

Маршрутизатор знаний — роль классификатора, ответственная за принятие решения о размещении любого материала пользователя (код, ссылка, документ, заметка) в правильном доме со знанием режима работы (индекс/указатель/снаружи).

**Не является ролью человека:** её играет программа-классификатор (система-исполнитель, без состояния); роль ≠ система.

## Входы (Артефакты)

| Вход | Форма | Источник |
|------|-------|----------|
| DP.KR.002 | карта классификации | PACK-digital-platform |
| DP.D.246 | тесты различения | PACK-digital-platform |
| Материал пользователя | файл/ссылка/заметка/метаданные | пользователь / агент |
| Контекст захвата (опционально) | project_name / domain / session_id | агент-инициатор |

## Выходы (Артефакты)

| Выход | Форма | Ответственность |
|-------|-------|-----------------|
| Классификация | класс (1-4) + уверенность + обоснование | маршрутизатор |
| Рекомендация дома | путь / имя домена / режим | маршрутизатор |
| Решение по карантину | вне оси / заблокирован с причиной | маршрутизатор |
| Метаданные размещения | owner / ttl / freshness-signal | маршрутизатор |

**Инвариант:** И1-И5 (DP.SC.058).

## Обязанности

1. **Классификация:** применить тесты DP.D.246 + DP.KR.002 § 2-5 к материалу → выбрать класс (1-4) или «вне карты».
2. **Обоснование:** каждое решение + тест, который сработал (И4 DP.SC.058).
3. **Карантин fail-closed:** неуверенность в классе или подозрение на PII/секрет/платёж → карантин (И5).
4. **Честный отказ:** если класс непонятен или вне карты → явное сообщение, не выдумка (И3).
5. **Batch-обработка:** если нужен проход по N файлов → сохранять решения, выявлять паттерны (для переиспользования тестов).

## Полномочия

- Читать любой материал пользователя (файлы, ссылки, метаданные).
- Писать метаданные размещения (теги, frontmatter, CSV-результаты).
- Консультировать человека (интегратора / пилота) с объяснением класса + альтернативы.
- **НЕ может:** автоматически перемещать файлы или писать в целевой дом (это роль /route-executor или интегратора).

## Связи

**Входящие ролевые связи (кто использует Маршрутизатор знаний):**
- R1 Strategist (пилот) — спрашивает интерактивно `/route`
- Агент при Capture (R15/R25) — вызывает batch-классификацию
- R85 (Разметчик) — интегратор, использует при организации базы

**Исходящие сервис-связи:**
- Читает из: DP.KR.002, DP.D.246, DP.SC.055 (режимы)
- Пишет в: DP.SC.058 (обещание)
- Реализует: DP.SC.057 + DP.SC.058

## Критерии качества

| Критерий | Признак успеха |
|----------|----------------|
| Полнота | Каждый материал получил либо класс, либо «вне карты» |
| Обоснованность | Каждое решение — с объяснением теста (И4) |
| Fail-closed | Сомнение → карантин, не угадывание (И5) |
| Consistency | Похожие материалы → похожие решения |

## Реализация

Скилл `/route` (CLI + MCP backend).  
Код: `~/.claude/skills/route/` (после Ф3.1).

**Примечание:** Маршрутизатор знаний — чистый классификатор, без enforcement-механизма. Enforcement (обеспечение соблюдения) — это роль Executor, которая запускает `/route --apply` и физически перемещает/организует файлы. Разделение ответственности: Router = decision, Executor = action.
