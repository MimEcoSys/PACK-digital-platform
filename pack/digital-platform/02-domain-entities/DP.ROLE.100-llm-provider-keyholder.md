# Держатель ключа провайдера языковой модели — DP.ROLE.100

> **Kind:** инфраструктурная роль (держит доступ, не пишет код сервисов). Исполняется пилотом лично, пока счёт провайдера личный.
> **Owner Role:** governance ИТ-платформы Холоникс (DP), фактически — пилот как владелец счёта.

## 1. Миссия

Держать один работающий ключ доступа к языковой модели и следить, чтобы каждый сервис платформы Холоникс (движок ответов, мост к агенту в VS Code, курсы OpenMAIC, Вече) пользовался этим ключом, а не заводил свой. Роль существует, чтобы смена модели или провайдера была одной правкой, а не четырьмя разъезжающимися.

**Граница (что НЕ делает):**
- НЕ выбирает модель или провайдера — решение пилота ([DP.SC.203](../08-service-clauses/DP.SC.203-holonix-llm-provider.md)).
- НЕ пишет код сервисов-потребителей — это Инженер сопровождения ([DP.ROLE.090](DP.ROLE.090-sustaining-engineer.md)) по конкретной правке.
- НЕ решает архитектурные вопросы отдельного сервиса (например, как движок ответов обрабатывает разбор ответа модели) — только то, откуда сервис берёт доступ к модели.

## 2. Обязанности

1. Хранить ключ доступа вне открытого кода (переменная окружения / секрет сервиса).
2. Следить, чтобы у всех четырёх сервисов-потребителей был рабочий ключ и правильная заявка модели.
3. Следить за балансом счёта провайдера, предупреждать пилота заранее до исчерпания.
4. При смене модели или провайдера — обновить конфиг всех сервисов разом, одной проверенной правкой, не по одному вразнобой.
5. Явно называть риск единой точки отказа: один счёт держит все сервисы разом — сбой счёта останавливает все четыре сразу, не один.

## 3. Полномочия

- Write: переменные окружения / секреты конфигов четырёх сервисов-потребителей (не их код).
- Read: панель провайдера (баланс, журнал расхода).
- НЕ имеет права менять код сервисов сверх строки подключения к модели — это выходит за роль (эскалация Инженеру сопровождения).

## 4. Вход / Выход

| | Артефакт |
|--|----------|
| **Вход** | Решение пилота о провайдере, модели и способе оплаты |
| **Выход** | Рабочий доступ к модели у всех четырёх сервисов + свидетельства проверки ([DP.SC.203](../08-service-clauses/DP.SC.203-holonix-llm-provider.md) §Свидетельства) |

## 5. Метрики

| Метрика | Норма |
|---------|-------|
| Доля сервисов-потребителей с рабочим ключом | 100% |
| Разброс модели/провайдера между сервисами | 0 — один и тот же ключ везде |
| Время между падением баланса ниже порога и предупреждением пилоту | до исчерпания, не после |
