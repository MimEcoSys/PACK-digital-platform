# Загрузчик контекста (DP.ROLE.105)

> **Уровень владельца:** часть IWE (DP.ROLE.001 §3.6). Роль играет функциональная подсистема IWE «Загрузчик контекста» (DP.ARCH.001 §4.2); у роли и подсистемы одно имя, но роль ≠ система: роль задаёт функцию, подсистема её выполняет.

## Обязанности

Носитель роли подаёт агенту инструкции и память по событиям сессии, держит резервную копию памяти.

## Метод

модульный экзокортекс (DP.EXOCORTEX.001).

## Рабочие продукты

контекст сессии агента; снимок перед сжатием беседы; копия памяти.

## Подсистема-владелец и её модули

Модули составляют подсистему, не роль (DP.ARCH.001 §11.1): Claude Code; `lazy-context-loader.sh`, `inject-*.sh`, `precompact-checkpoint.sh`, `precompact-restore.sh`, `memory-exocortex-sync.sh`; git и файловая система ОС.

**Когда работают:** Claude Code — при старте сессии читает инструкции и память; хуки — на событиях ввода и сжатия беседы; `memory-exocortex-sync.sh` — при записи файла памяти.

## Прежние имена и роли программ внутри

- **Прежние имена:** R30 Контекст-менеджер (псевдоним, DP.ROLE.001 §3.7); прежнее имя подсистемы — экзокортекс.
- **Роли программ и модулей внутри подсистемы (DP.ARCH.001 §17):** нет.
