# Профилировщик (DP.ROLE.116)

> **Уровень владельца:** часть платформы (DP.ROLE.001 §3.6). Роль играет программа платформы (исполнитель I11, DP.ROLE.001 §3.1); роль ≠ программа: роль задаёт функцию, программа её выполняет.

> **Прежнее обозначение** — номер R28 (DP.ROLE.001 §3.2). Номер остаётся псевдонимом в каталоге (§3.7); у того же номера в шаблоне и скиллах другая роль — Диагност (DP.ROLE.042).

## Обязанности

Носитель роли пересчитывает производные показатели цифрового двойника — ступень, освоение по областям, пробелы, индекс агентности — из собранных данных (вовлечённость) и истории обучения и записывает их в слой производных данных (DP.ARCH.003 принцип 1).

Носитель роли — единственный, кто пишет в слой производных данных; интерфейсы (бот, MCP, командная строка) только читают (DP.ARCH.003 принципы 4–5).

## Метод

Носитель роли работает по принципам DP.ARCH.003 (разделение расчёта и чтения); ступени и их вычисление — DP.METHOD.020.

## Рабочие продукты

производные показатели в цифровом двойнике (слой производных данных).

## Исполнитель

Программа расчёта (`DS-ai-systems/profiler/scripts/dt_calc.py`) и отдельная программа пересчёта (`recalculate_derived.py`) — DP.ARCH.003, раздел «Связи».

**Когда работает:** по расписанию в 04:30 МСК и по требованию; целевой режим — пересчёт по событию (DP.ARCH.003 принцип 6).

## Чего не делает

- Не собирает данные: собранные данные пишет бот (DP.ARCH.003, раздел «Связи»).
- Не показывает показатели пользователю: их читают интерфейсы.
- Не назначает ступень по самоотчёту: ступень вычисляется (DP.METHOD.020).
