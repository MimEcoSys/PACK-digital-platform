# Переводчик (DP.ROLE.121)

> **Уровень владельца:** часть платформы и часть IWE (DP.ROLE.001 §3.6). Роль играют две подсистемы с одним именем — у платформы и, по выбору, у IWE (DP.ARCH.001 §4.1, §4.2): это два экземпляра одной программы, а чья подсистема — решает тест DP.ARCH.001 §2 «чей экземпляр выполняет функцию». Так же одна роль Диагноста играется и платформой, и внутри IWE (DP.ROLE.042). Роль ≠ система: роль задаёт функцию, подсистема её выполняет.

## Обязанности

Носитель роли переводит тексты с русского на английский так, что системные термины названы утверждёнными английскими именами из словаря понятий. Если утверждённого имени нет, неутверждённое имя он не выдаёт молча: показывает его отдельным списком «русский термин → имя, источник».

- **У платформы:** переводит для всех тексты шаблона IWE и карточки Библиотеки методов; отдаёт словарь утверждённых имён для инструкции ИИ клиента Open.
- **У IWE (по выбору):** переводит тексты пользователя по тому же словарю.

## Метод

Общее описание метода не выделено. Обещание Переводчика и пять способов его выполнения утверждены в РП-620 Ф2; опоры обещания — DP.SC.188, DP.SC.203 (черновики). Имена утверждает пилот в карточке понятия в паке; словарь — снимок утверждённых имён из графа понятий и ручной файл кандидатов.

## Рабочие продукты

Английские редакции текстов (документы шаблона, карточки Библиотеки, тексты пользователя); список неутверждённых имён; снимок словаря для инструкции ИИ.

## Подсистемы-владельцы и их модули

Модули составляют подсистемы, не роль (DP.ARCH.001 §4.1, §11.1):
- платформа — перевод шаблона при обновлении основной ветки (автоматическая сборка `translate-sync` в репозитории шаблона на GitHub), iwe-translation-engine;
- IWE — `translate.py`, по вызову пользователя.

## Прежние имена и роли программ внутри

- **Прежние имена:** нет.
- **Роли программ и модулей внутри подсистемы:** нет.
