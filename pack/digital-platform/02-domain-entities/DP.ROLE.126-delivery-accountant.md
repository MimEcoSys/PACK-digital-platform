# Учётчик доставки (DP.ROLE.126)

> **Уровень владельца:** часть платформы (DP.ROLE.001 §3.6); функциональная часть подсистемы «Вестник» (DP.ROLE.122). Выделен 18.11.2026: часть его обязанностей раньше выполняла роль «Notification Dispatcher» (DP.ROLE.044, «зафиксировать статус»). Не путать с Учётчиком событий (подсистема DP.ARCH.001 §4.1): Учётчик доставки ведёт журнал Вестника, Учётчик событий принимает события в общий учёт платформы.

## Обязанности

| Обязанность | Этап конвейера (РП-568 Ф23) |
|---|---|
| Записать исход каждой попытки доставки из закрытого списка (доставлено, заблокирован, временный сбой, неизвестно; отсечено с причиной) | Б12 «Учёт» |
| Привязать реакции человека (нажатие, «почему я это получил», «не присылать такое», блокировка бота) к выпуску | В4 «Реакция» |
| Отметить канал, если бот заблокирован (может запустить приостановку правила «нет пути») | Б12, А7 |
| Передать события доставки в общий учёт платформы | Б12 |
| Отдать данные для табло и выгрузки | Б12, В5 |
| Хранить обезличенный след доставки ограниченный срок после удаления правила | А8 |

**Граница.** Учётчик доставки не считает сводку для табло (Составитель табло) и не решает о доставке. Требования к записи исхода (запись до отправки, исход не позже 1 минуты) - DP.SC.177, раздел «Учёт и табло».

## Рабочие продукты

Журнал доставки и реакций.

## Модули

Целевое - программа «Центр уведомлений» (DP.ROLE.122, раздел «Модули»). Сейчас журнал отправок ведёт Telegram-бот.

- **Прежние имена:** часть роли «Notification Dispatcher» (DP.ROLE.044, до 18.11.2026).
