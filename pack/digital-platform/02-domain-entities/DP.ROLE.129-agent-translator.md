# Переводчик для ИИ-агентов (DP.ROLE.129)

> **Уровень владельца:** часть IWE (DP.ROLE.001 §3.6) **под вопросом**: программа сборки может работать только у автора шаблона, а для таких ролей §3.6 знает прецеденты отказа (DP.ROLE.102, DP.ROLE.103). Решает пилот. Подсистемы и модуля ещё нет: программы сборки и навыка роли нет, заявка в справочник подсистем IWE подана в РП-616 (И-31, 24.11.2026). Роль ≠ система: роль задаёт функцию, сейчас её играет ИИ-агент Claude.
>
> **Не путать с ролью «Переводчик» (DP.ROLE.121).** Тот переводит тексты с русского на английский по словарю понятий. Этот переводит методы IWE с языка одного ИИ-агента на язык других; русский текст навыка остаётся русским.

## Обязанности

Носитель роли добивается, чтобы методы IWE, записанные как навыки для Claude Code, выполнялись в других ИИ-агентах так же полно или с честно названным ограничением.

- **Отвечает за общую версию.** Запускает программу сборки после изменений навыков и следит, чтобы проверка расхождения проходила. Руками общую версию не правит (DP.D.389).
- **Находит шаги, которые держатся на особых возможностях Claude:** вопрос с вариантами, поручение помощнику, вызов одного навыка из другого, список задач, отправка файла. Сигнал для этой работы механический: проверка шаблона находит в исходном навыке особый инструмент Claude без записанного требования и запасного пути.
- **Вносит в исходный навык требование и запасной путь.** Порядок сведён с контрактом хоста (DP.IWE.011 §5): шаг навыка называет абстрактную операцию контракта, а переходник агента решает, чем её выполнить. Запасной путь словами пишется для агента, у которого по переходнику этой операции нет. Например: «если у агента нет вопроса с вариантами — дай пронумерованный список и попроси ответить цифрой». Операций, которых в контракте ещё нет (вопрос с вариантами, отправка файла), роль не изобретает: предлагает расширить перечень контракта, решение — по архитектурной проверке.
- **Предлагает класс навыка:** «общий», «только для Claude» или «служебный, не раздаётся». Кто утверждает класс, ещё не решено; предложение — мейнтейнер навыков (DP.ROLE.056), для навыков человека — сам человек.
- **Принимает перевод под агента только после пробы** в этом агенте на наборе проверочных задач IWE. Проба идёт по заранее записанной гипотезе и по чек-листу, независимому от проверяемого агента. Целевой агент (Codex, Kimi Code) участвует в пробе, но вердикт выносит не он один.

## Границы

**Роли рядом:**
- **Автор навыка (DP.ROLE.057)** пишет метод. Переводчик метод не меняет: добавляет требования и запасные пути; принимает ли их автор, будет записано в описании DP.ROLE.057 (предложение РП-592 Ф7).
- **Мейнтейнер навыков (DP.ROLE.056)** ведёт каталог навыков; утверждение класса навыка — предложение РП-592 Ф7, в описание DP.ROLE.056 ещё не внесено.

**Чего роль не делает:**
- Не переносит защитные проверки (хуки): стандарта для них нет, обязательные запреты держатся ниже агента. Их перенос ведёт РП-592 Ф6.
- Не доставляет общую версию пользователям: это конвейер доставки шаблона (РП-529).
- Не меняет содержание метода.

## Сценарии (IntegrationGate, шаг 2)

- **С1.** Автор поправил навык → Переводчик запустил сборку → проверка шаблона подтвердила, что общая версия совпадает со сборкой.
- **С2.** Появился навык с шагом, который держится на особой возможности Claude → проверка шаблона дала сигнал → Переводчик предложил класс, требование и запасной путь в исходный навык → автор принял → сборка.
- **С3.** Подключаем нового агента → переходник в контракте хоста → проба на проверочных задачах → агент получает общую версию.
- **С4.** Человек открывает день в Codex или Kimi Code → навык находится и выполняется; если нужной возможности нет, агент идёт запасным путём или называет ограничение и останавливает зависимый шаг.

## Входы и рабочие продукты

**Входы:** версия разработчика навыков (папка навыков Claude Code), контракт хоста IWE и его переходники, результаты проб в агентах.

**Рабочие продукты:** общая версия навыков (через программу сборки), правки исходных навыков (требования, запасные пути, класс), предложения по переходникам агентов и перечню операций контракта хоста, набор проверочных задач и записи проб.

## Модули

Программа сборки — инструмент роли, без ИИ: сокращает заголовок до полей стандарта, исправляет адреса программ, пропускает служебные навыки, раскладывает копии по папкам агентов, проверяет расхождение. Пока не создана: место и устройство — по архитектурной проверке РП-592 Ф7.
