# Архитектор личной структуры IWE (DP.ROLE.131)

> **Kind:** Функциональная роль (FPF A.2). Черновик: имя и граница приняты, обещание, сценарии и носитель не определены. Порядок дальше — по IntegrationGate: обещание → сценарии → уточнение роли → реализация; ведётся в РП-526.

## 1. Миссия

Дать человеку предложение по структуре его собственных хранилищ, когда она мешает работе: один вид материала лежит в нескольких местах, для вида материала нет дома, хранилище разрослось, человек пришёл со своей раскладкой из других программ.

## 2. Граница с соседними ролями

| Роль | Что делает она | Что делает Архитектор личной структуры |
|---|---|---|
| R5 Архитектор (платформенный архитектор) | задаёт общую структуру IWE для всех пользователей: какие бывают хранилища, образец карты маршрутизации, стартовый набор | применяет общую структуру к хранилищам одного человека; общую схему не меняет |
| Разметчик ([[DP.ROLE.085]]) | размечает материал внутри готовой структуры и первым замечает её изъяны; структуру не меняет | получает эти наблюдения и готовит предложение о перестройке |
| Маршрутизатор знаний ([[DP.ROLE.088]]) | рекомендует дом единице материала по карте | меняет саму карту вместе с человеком, когда меняются дома |
| навык создания хранилища (`/repo-new`) | проводит создание одного нового хранилища по просьбе | решает, нужно ли новое хранилище, и в каком порядке перестраивать существующие |

## 3. Полномочия

- **Читает** хранилища человека, его личную карту маршрутизации ([[DP.KR.002]] §9) и наблюдения Разметчика.
- **Предлагает** человеку вариант перестройки с объяснением, зачем она нужна и во что обойдётся.
- **Не переносит** файлы и не создаёт хранилища без решения человека; чужие личные данные и секреты не трогает.

## 4. Открытые вопросы (РП-526)

- **Q1.** Обещание пользователю и сценарии: когда роль срабатывает (после обновления, по наблюдениям Разметчика, по просьбе).
- **Q2.** Методы: по каким принципам рекомендовать структуру; какие лучшие практики взять; насколько для обычного пользователя нужна ось типов 2.1–2.4. Сигналы от Разметчика: неоднозначный маршрут, расхождение карты и факта, повторно нет дома; наблюдения с числом без диагноза (размер дома, давность использования) — см. [[DP.ROLE.085]] §1б.
- **Q3.** Носитель: отдельный навык, расширение навыка создания хранилища или шаг Разметчика с передачей.
