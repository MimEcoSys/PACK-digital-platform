# DP.M.245 — CP-Profile Adaptive Facilitation

## Суть

При проектировании LLM-агента сопровождения (Pack Creator, курс, менторство) глубина взаимодействия калибруется по `cp.iwe`-срезу профиля пользователя.

## Forces

_Какие конкурирующие давления удерживает метод._

| Force | Tension |
|-------|---------|
| Персонализация глубины ↔ масштабируемость шаблонов | Full SPF даёт максимальную адаптацию, но требует от пользователя уметь оригинировать distinction'ы; Assembly масштабируется, но рискует превратиться в «меню из чеклиста» |
| Глубина для опытных ↔ защита новичков | Опытным пользователям нужен review формы, а не готовый шаблон; новичкам dangerous дать full SPF, но они могут быть недовольны «упрощёнкой» |
| Измерение профиля ↔ отсутствие данных | Без cp.iwe-профиля невозможно точно калибровать, а fallback на Assembly снижает ценность для продвинутых пользователей |

## Трёхуровневая модель

| Уровень | Условие | Режим агента |
|---------|---------|-------------|
| Assembly | `cp.iwe ≤ 2` | Агент предлагает готовые шаблоны из соседних Pack'ов; пользователь выбирает из чеклиста |
| Hybrid | `cp.iwe = 3` | Агент предлагает + пользователь адаптирует под домен |
| Full SPF | `cp.iwe ≥ 4` | Пользователь оригинирует distinction'ы; агент review'ит форму |

## Default при отсутствии профиля

Режим Assembly + CTA: «Пройдите диагностику для точной калибровки» (Диагност, DP.ROLE.042).

## Принцип

Агент не устанавливает глубину произвольно — она зависит от измеренного профиля. Без профиля — наименее опасный уровень (assembly: агент делает больше, пользователь выбирает из готового).

## Применимость

Любой facilitation-паттерн с неоднородной аудиторией: Pack Creator (R30), курсы, менторство, код-ревью, онбординг.

## Bias-Annotation

_Куда систематически съезжает внимание практикующего._

| Bias | Direction of distortion |
|------|--------------------------|
| «Средний пользователь» — выбор Hybrid по умолчанию | Практикующий склонен выбирать middle-режим как «золотую середину», даже когда данные профиля требуют Assembly или Full SPF |
| Агент делает больше, чем нужно (over-facilitation) | Особенно при отсутствии профиля агент тянется к более активной роли, вместо того чтобы явно запросить диагностику и fallback на Assembly |
| Пренебрежение диагностикой как prerequisite | Давление «быстро дать результат» приводит к пропуску шага измерения cp.iwe, и тогда калибровка становится произвольной |
