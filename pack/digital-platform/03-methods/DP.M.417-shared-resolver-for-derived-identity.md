# DP.M.417 — Общий resolver для независимо вычисляемой производной идентичности

## Описание

Когда несколько независимых компонентов вычисляют одну и ту же производную идентичность (например, «кто я как держатель замка») по одинаковой формуле, продублированной в каждом месте, — фикс формулы в одном месте не распространяется на остальные автоматически. Системное решение — вынести вычисление в один общий resolver-скрипт/функцию с параметром fallback, а не патчить каждое место точечно при следующей находке.

## Forces

| Force | Tension |
|-------|---------|
| Скорость точечного фикса ↔ полнота покрытия всех вычислителей | Пропатчить то место, где проявился баг, — быстро и локально; но если формула продублирована в N местах независимо, точечный фикс закрывает симптом только там, оставляя остальные N-1 источником следующей находки того же класса |
| Локальный fallback-дефолт каждого вызывающего ↔ единство формулы | Общий resolver обязан сохранять прежний дефолт каждого вызывающего на случай «ничего не настроено», иначе централизация меняет поведение там, где раньше было безопасное отсутствие настройки |

## IPO

**Вход:** N независимых мест в кодовой базе, каждое вычисляет одну и ту же по смыслу производную идентичность своей копией формулы; баг найден и исправлен в одном из них.

**Процесс:**
1. Найти все места, независимо вычисляющие ту же идентичность (grep по семантике вычисления, не только по имени функции — реализации могли разойтись текстуально)
2. Вынести формулу в общий resolver (скрипт/функцию) с параметром fallback, сохраняющим прежний дефолт каждого вызывающего
3. Переключить все найденные места на общий resolver вместо собственной копии формулы

**Выход:** одна формула вычисления идентичности с одной точкой правки; следующий фикс формулы автоматически распространяется на всех вызывающих.

## Тест

«Если формулу вычисления идентичности снова придётся поправить — сколько мест нужно тронуть?» Один общий resolver — метод соблюдён. N точечных копий — следующая находка того же класса неизбежна.

## Bias-Annotation

| Bias | Direction of distortion |
|------|--------------------------|
| Место обнаружения бага кажется единственным местом бага | Фикс делается там, где заметили симптом; вопрос «а кто ещё вычисляет то же самое» не задаётся, пока не всплывёт второй-третий инцидент того же класса в других компонентах |
