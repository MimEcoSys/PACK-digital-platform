# DP.M.474 — Фильтр «упоминание ≠ команда»: смещение первого действующего триггера

**Симптом.** Хук закрытия срабатывал на слове-триггере («закрывай»), встреченном внутри цитаты или вопроса — наивное совпадение подстроки не отличало произнесённую команду от упоминания того же слова.

**Метод.** Единый фильтр вычисляет смещение первого триггера, который реально действует (не внутри кавычек, не часть вопроса, не под отрицанием) — не смещение первого текстового совпадения. Маска цитат заменяет содержимое цитаты нейтральными символами той же длины, чтобы позиции триггеров вне цитаты не сдвигались. При отказе самого фильтра (например, парсинг сломался) используется прежний, более грубый расчёт — fail-open, а не полный отказ хука.

**Проверка.** Тесты на границы порога (599/600/601 символов) плюс мутационная проверка порчи фильтра — искажение логики должно ронять тест, не проходить незамеченным.

**Применимо к.** Любому текстовому триггер-детектору (hook, TG-бот, command-parser), где строковое совпадение ключевого слова используется как сигнал команды.

## Связи

- `DP.FM.170` — literal guard pattern mismatch: родственный класс «наивное текстовое совпадение в guard/hook ненадёжно», но противоположный отказ (guard слишком строгий, не матчит реальное; здесь — слишком мягкий, матчит лишнее).
- `DP.FM.456` — static marker whitelist spoofable: тот же домен «надёжность текстового маркера», другой механизм отказа (предсказуемость маркера, не контекст совпадения).
- `DP.FM.454` — quote-grounding проверяет наличие цитаты, не её релевантность: смежно только по слову «цитата», предметная область другая (LLM-оценщик ДЗ), не дубль.
