# DP.M.501 — Пропагация терминологии между Pack-документами требует смыслового решения, не find/replace

## Проблема

Изменение терминологии/схемы уже согласовано и применено в одном документе (источнике). Другие документы (того же Pack или других Pack-репозиториев) цитируют или реализуют этот источник и используют старые термины. Статус «решение уже принято, это просто пропагация» создаёт иллюзию, что перенос — механическая операция.

## Метод

1. Найти все вхождения старого термина/схемы по всем документам, которые цитируют или реализуют источник.
2. Для КАЖДОГО вхождения — явное смысловое решение: какой из новых терминов соответствует тому, что это конкретное утверждение фактически измеряет (а не позиционное/синтаксическое совпадение).
3. Слепая замена (find/replace по тексту) запрещена: минимум одно вхождение обычно читается по-другому при новой схеме (пример: параграф читался бы как скрытая арифметика между несовместимыми шкалами).
4. После замены — финальный sweep по остаточным старым терминам (grep по всем старым меткам) на предмет «забытых» мест.

## Тест

«Проверено ли каждое вхождение по смыслу (что оно измеряет), а не только как позиция для замены строки?» Нет → риск минимум одного семантически сломанного места, которое пройдёт синтаксическую проверку.
