# DP.M.545 — Повторяемая проверка матрицы прав с сигналом о расхождении

## Метод

Контракт прогона задаёт матрицу: субъект, объект, операция, ожидаемый доступ. В неё входят разрешённые и запрещённые комбинации, положительные и отрицательные контроли с известными объектами. Результаты сохраняются вместе с версией ожидаемой политики и условиями проверки.

Фактический результат сравнивается прежде всего с ожидаемой политикой. Сравнение только с предыдущим прогоном может закрепить прежнюю ошибку. Изменение относительно прошлого результата также является поводом проверки, но может быть разрешённым изменением политики. Расхождение вызывает сигнал ответственному с указанием проверенной комбинации.

Прогоны повторяются после изменений прав и по графику, выбранному по риску. Частота и реакция на отказ определяются проектом явно. Метод не заменяет своевременный отзыв прав и не доказывает непрерывную безопасность между пробами. Проверка доступности процесса отвечает на другой вопрос.

## Проверка результата

Контролируемое изменение разрешения меняет ожидаемую ячейку; ошибочный результат вызывает сигнал. Опечатка пути, недоступность сервиса и отсутствие тестовых полномочий обозначаются отдельно, не выдаются за подтверждённый отказ по правам.

## Отличие от соседей

DP.METHOD.128 проверяет воспроизведение известного бага детектора; DP.M.517 — одноразовую приёмку оповещений. Здесь выход — повторяемое свидетельство по матрице доступа. Правило, что отказ проверки не блокирует закрытие, из соседнего метода не переносится.
