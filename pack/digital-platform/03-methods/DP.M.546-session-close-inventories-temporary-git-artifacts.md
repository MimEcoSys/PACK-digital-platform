# DP.M.546 — Инвентаризация собственных временных Git-ссылок при закрытии

## Метод

Снимок имён и значений refs при открытии и их сравнение при закрытии выделяют кандидатов изменений. Эти снимки не доказывают, кто создал ветку или тег. Git не даёт надёжной универсальной даты создания ветки; возраст коммита не является возрастом ссылки.

Собственные временные ссылки учитываются в журнале их создания с назначением и владельцем. При закрытии сведения журнала сопоставляются с текущими refs. Для каждого подтверждённо своего артефакта фиксируется исход: безопасное удаление после проверки либо явная передача с владельцем, сроком и причиной сохранения.

Удаление допустимо только при доказанном владении и безопасности: ссылка не сохраняет единственную нужную копию работы, её защитное назначение завершено, она не нужна другой активной работе. Неизвестное происхождение или неполное доказательство требуют сохранения и разбора, а не автоматической очистки.

## Проверка

Собственная резервная ветка попадает в инвентаризацию; чужая ветка из того же временного окна не присваивается сессии. Единственная копия незавершённой работы сохраняется. Отчёт содержит решение по своим ссылкам, а по неустановленным — предел атрибуции. Само сравнение снимков является наблюдением и не выполняет удаления.

## Исторический пример

В исходной сессии резервная ветка после рискованной операции осталась незамеченной процедурой закрытия. Метод отделяет обнаружение ссылок от права их удалить.
