# DP.M.551 — Дедупликация сканера по корню рабочего дерева с проверкой охвата

## Входы и выходы

Вход: список путей рабочего пространства и определённая единица учёта — физическая рабочая копия. Выход: одна проверка на такую копию с явным перечнем исключённых или неразрешённых путей.

## Метод

1. Отдельно определить входной фильтр: какие обычные копии, linked worktree и алиасы входят в скан.
2. Для допущенных путей разрешить физический корень рабочего дерева через Git и нормализацию пути. Алиасы одного корня объединять; разные корни не объединять лишь из-за общей истории Git.
3. Ошибку определения корня сохранить как неизвестную идентичность. Запасная строка пути не доказывает тождество.
4. Проверить алиас единственной копии, два алиаса одной копии и два рабочих дерева с общей историей. Не исключать все симлинки: симлинк может быть единственным входным путём.

## Историческая граница охвата

FMT-exocortex-template `66e9ac0e47523099102cceb4758c08521758e642` добавляет дедупликацию по `git rev-parse --show-toplevel`. Однако до неё стоит фильтр `if [ ! -d "$dir/.git" ]; then return; fi`: linked worktree с файлом `.git` отсеивается. Эта версия не подтверждает обещание отдельной проверки всех worktree. Правильный ключ и полнота входного множества — разные проверки.

## Forces

Устранение повторного счёта снижает шум, но слишком широкое объединение скрывает независимые изменения разных рабочих копий. Охват скана задаётся задачей, а не удобством признака `.git`.

## Bias-Annotation

Название «репозиторий» склоняет смешивать общую историю Git и рабочее дерево. Успешное устранение дублей может скрыть пропуск целого класса входов; проверять обе оси.
