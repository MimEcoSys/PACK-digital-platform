# DP.M.571 — Передача решения между этапами: поле производителя, не разбор текста

## Входы и выходы

Вход: этап-производитель, который принимает решение (например, «какие РП переносятся»), и этап-потребитель. Выход: машиночитаемое поле, которое потребитель читает вместо пересказа в свободном тексте.

## Метод

1. Производитель пишет решение отдельным структурированным полем (например, `carry_over_wps`).
2. Потребитель берёт решение только из поля; упоминание в тексте ≠ решение.
3. Для старых данных без поля решение не реконструируется задним числом: потребитель показывает текст человеку.

## Пример

Закрытие недели упоминало РП-250 в тексте, и пул принял его за перенос. После перехода на поле `carry_over_wps` ложное попадание исчезло; для W43 списка нет, и он не выдумывается.
