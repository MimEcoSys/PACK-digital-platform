# DP.M.629 — Индекс журнала верен, пока файл таков, каким его оставил сам процесс

## Проблема

Долгоживущий процесс (приёмник очереди событий) на каждый запрос под замком перечитывал и заново проверял весь журнал с дозаписью. С ростом журнала пропускная способность упала примерно до 0,75 принятых записей в секунду при 3 049 записях.

## Метод

1. Процесс держит **малый индекс** журнала: выданные квитанции, хвост, число записей, длину проверенной части.
2. После каждой своей успешной дозаписи процесс запоминает **отпечаток файла**: устройство, inode, размер, mtime в наносекундах (`st_dev, st_ino, st_size, st_mtime_ns`), а вместе с ним метаданные потока, по которым индекс строился.
3. Перед использованием индекса процесс сравнивает текущий отпечаток с запомненным:
   - совпадают и отпечаток, и метаданные — файл никто, кроме процесса, не менял, и индекс используется;
   - не совпадает (ротация, замена файла, чужая запись, усечение) — **полная проверенная перезагрузка** журнала, индекс строится заново.
4. **Сбой дозаписи сбрасывает индекс**: после неудачной записи состояние файла неизвестно, и следующий запрос идёт через полную перезагрузку.

Суть метода: доверять нужно не «давности» индекса, а тому, что файл после процесса никто не трогал.

## Граница

- Индекс используется **только под замком писателя** и стоит на пути решения о приёме: по нему проверяется ожидаемый хвост (транспортный CAS: несовпадение — отказ `ParentMismatch`), ёмкость потока и назначается порядковый номер приёма. Поэтому верность отпечатка — условие верности решения, а не только скорости.
- Это не отмена DP.M.536, а то решение о снапшотах, которое DP.M.536 в разделе «Применимость» оставляет отдельным: журнал остаётся единственным источником истины, индекс — его производная, и при любом сомнении (отпечаток или метаданные не совпали, дозапись упала) процесс возвращается к полному проверенному чтению журнала.
- Метод применим, пока все записи в журнал идут под тем же замком. Чужой писатель, обходящий замок, ломает предпосылку независимо от отпечатка.
