# DP.METHOD.243 — env-var fallback для переносимости путей

## Суть метода

Shell-скрипт, зависящий от другого скрипта/ресурса платформы, ищет его путь в порядке приоритета: (1) переменная окружения (`IWE_SCRIPTS` и подобные), если задана; (2) относительный путь по умолчанию, вычисляемый от расположения самого скрипта — как fallback, если переменная не задана.

## Обоснование

Относительный путь по умолчанию работает только при стандартной структуре установки. Переменная окружения позволяет переопределить расположение для нестандартных установок (другая корневая директория, тестовое окружение) без правки самого скрипта — при этом сохраняется совместимость «из коробки» через fallback.

## Применение

Любой shell-скрипт платформы, зависящий от расположения других скриптов/ресурсов, которое может отличаться между установками.

## Граница

Порядок «переменная окружения сначала, расположение скрипта — запасной вариант» годится, пока контракт переменной — расположение инструментов (`IWE_SCRIPTS`: где лежат скрипты платформы). Он не годится, если переменная описывает корень данных, с которыми работают сейчас, и её легитимно подменяют вызывающие (раннеры фикстур и проб).

Случай из практики: путь к библиотеке синхронизации (`GIT_SYNC_LIB`) резолвился через `IWE_WORKSPACE`. Два вызывающих скрипта (`wp-sync-bundle-batch.sh`, `wp-pipeline-checks-runner.sh`) намеренно подменяют `IWE_WORKSPACE` для прогонов на фикстурах и пробах; библиотека же физически лежит рядом со скриптом. Каждый такой прогон не находил библиотеку (`GIT_SYNC_STATUS=checker_unavailable`, код выхода 3 на чистой фикстуре). Исправление — резолвить путь от `BASH_SOURCE` (расположения самого скрипта), как это уже было сделано для `PHASE_DIGEST_SCRIPT` выше в том же файле. Дефект пойман живым прогоном `wp-pipeline-checks-runner.sh`.

Проверка перед применением метода: «что по контракту описывает эта переменная — расположение инструментов или корень данных, и подменяют ли её вызывающие для фикстур?» Корень данных и есть подмена → резолвить от `BASH_SOURCE`, а не от переменной.
