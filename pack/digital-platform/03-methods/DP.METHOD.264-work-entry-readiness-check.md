# DP.METHOD.264 — Проверка готовности агента перед работой

> **Статус: кандидат, не признанный метод.** Опора - паттерн готовности к входу в работу FPF A.15.5. Агент по Ритуалу открытия уже делает часть этого (роль, работа, РП, метод). Внешний сценарий - РП-552 Ф7, сценарий 3. Признание - после первых свидетельств.

### Definition

Перед первым действием агент называет пользователю сведения, с которыми начинает работу, по отношениям к работе (DP.D.371), и даёт один из четырёх итогов готовности с условием перепроверки.

### Purpose

Предотвратить ошибки до начала работы: пробел в сведениях называется до действия, а не обнаруживается после ошибки.

### Forces

| Force | Tension |
|-------|---------|
| Полнота против шума | Полный перечень перед каждым действием превращается в ритуал; проверка делается на входе в работу, не перед каждым действием |
| Видимость против устройства | Пользователю важно, с чем агент начинает, а не как собран контекст; показывается только видимое снаружи |
| Готовность против скорости | «Не готов» останавливает работу; пользователь может сам решить идти дальше с названным пробелом |

### Inputs

| Input | Description | Required? |
|-------|-------------|-----------|
| Задание | Что сделать, ограничения, срок | Yes |
| Карточка РП и передача работы | План, решения, прошлые результаты и проверки | Yes |
| Библиотека методов или описания методов | Подходящее описание метода | No |

### Action

1. Назвать описание метода, по которому пойдёт работа, или сказать, что подходящего нет.
2. Назвать сведения о предмете, с которыми начинается работа.
3. Назвать задание с ограничениями, обязательствами и разрешениями.
4. Назвать учтённые результаты и проверки прошлой работы.
5. Дать итог: готов; готов с названными пробелами; не готов; неизвестно - и условие, при котором проверку нужно повторить.
6. При «не готов» или «неизвестно» назвать пробел и не действовать, пока пробел не закрыт или пользователь не решил идти дальше.

### Outputs (Work Products)

| Output | Link | Description |
|--------|------|-------------|
| Строка готовности | (первое сообщение агента в сессии) | Перечень сведений и итог готовности |

### Roles Involved

| Role | Responsibility in This Method |
|------|------------------------------|
| Агент | Проводит проверку и показывает итог |
| Пользователь (пилот) | Решает, идти ли дальше при названных пробелах |

### Key Distinctions

- [DP.D.371](../02-domain-entities/DP.D.371-information-function-relative-to-work-vs-information-kind.md): перечень строится по отношениям сведений к работе, а не по видам документов.

### Bias-Annotation

Склонность агента ставить «готов», чтобы не задерживать пользователя. Противовес: итог «неизвестно» допустим и честнее ложного «готов».
