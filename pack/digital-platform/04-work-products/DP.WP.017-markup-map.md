# Карта разметки

## 1. Определение

**Карта разметки** — рабочий продукт Разметчика ([[DP.ROLE.085]]): по строке на элемент материала пользователя. В строке — источник элемента, метка схемы («что это»), пометка области, уверенность (высокая / низкая) и отметка, согласовал ли метку пользователь; если хранилища дома ещё нет — статус «ждёт хранилища» ([[DP.ROLE.085]] §1б п. 10).

## 2. Назначение

Показать пользователю, как агент понял его материал, до того как это понимание попадёт в стратегию, план или руководство; и дать потребителю (сессии стратегирования, сборке руководства) готовый ответ «что брать».

## 3. Формы по схемам

| Схема меток | Форма карты | Где хранится |
|---|---|---|
| Руководство (типы 2.1–2.4) | индекс типов `type-index.json` | `.structurer/` в пространстве пользователя |
| Стратегия (цель / неудовлетворённость / обязательство / предложение / история / в архив / отложено) | раздел «Разметка нового»: 5–7 групп, группа «проверьте», список «требует вашего решения», список «Отложено при разметке», строка учёта | черновик плана недели; в первой сессии и в отдельной беседе разметки — файл карты во входящих до переноса в план |

## 4. Критерии приёмки

- У каждого элемента одна метка и одна пометка области.
- Чужие личные данные, секреты и платёжные данные в карту не цитируются: только путь и причина.
- За одно согласование — не больше 40 меток, остальное в списке «Отложено».
- До согласования пользователем ничего из карты не записано в дома меток.
- Есть строка учёта: сколько меток, сколько изменил пользователь, сколько отложено.

## 5. Что происходит после согласования

После согласования дальнейшее действие определяется схемой и меткой. Для стратегической схемы запись выполняется по шагу «Разметка нового» — колонке «Куда идёт после согласования» схемы меток и таблице «Когда и кто записывает»: решения в постоянные документы записывают соответствующие этапы сессии стратегирования; список «Отложено при разметке» записывает Разметчик; история остаётся на месте. Для схемы руководства Разметчик записывает индекс типов. Дома определяет личная карта маршрутизации пользователя ([[DP.KR.002]] §9); при отсутствии хранилища применяется [[DP.ROLE.085]] §1б п. 10. Карта разметки при этом остаётся записью одного согласования, а постоянной картой материала служат дома.
