# Карта разметки

## 1. Определение

**Карта разметки** — рабочий продукт Разметчика ([[DP.ROLE.085]]): по строке на элемент материала пользователя. В строке — источник элемента, метка схемы («что это»), пометка области, уверенность (высокая / низкая) и отметка, согласовал ли метку пользователь.

## 2. Назначение

Показать пользователю, как агент понял его материал, до того как это понимание попадёт в стратегию, план или руководство; и дать потребителю (сессии стратегирования, сборке руководства) готовый ответ «что брать».

## 3. Формы по схемам

| Схема меток | Форма карты | Где хранится |
|---|---|---|
| Руководство (типы 2.1–2.4) | индекс типов `type-index.json` | `.structurer/` в пространстве пользователя |
| Стратегия (цель / неудовлетворённость / обязательство / предложение / история / в архив / отложено) | раздел «Разметка нового»: 5–7 групп, группа «проверьте», список «требует вашего решения», список «Отложено при разметке», строка учёта | черновик плана недели; в первой сессии — файл карты во входящих до переноса в первый план |

## 4. Критерии приёмки

- У каждого элемента одна метка и одна пометка области.
- Чужие личные данные, секреты и платёжные данные в карту не цитируются: только путь и причина.
- За одно согласование — не больше 40 меток, остальное в списке «Отложено».
- До согласования пользователем ничего из карты не записано в дома меток.
- Есть строка учёта: сколько меток, сколько изменил пользователь, сколько отложено.

## 5. Что происходит после согласования

Согласованные элементы записываются в постоянные дома своих меток по личной карте маршрутизации пользователя ([[DP.KR.002]] §9). Карта разметки при этом остаётся записью одного согласования, а постоянной картой материала служат дома.
