# DP.FM.021 — Нулевой слот блокирует min()-агрегацию ступени

## Симптом

`stage_raw=4, W=0` → `min(4,0)=0` → NOOP (cur=1 > computed=0). Высокие значения остальных слотов не влияют на итог. Система застревает на cur до ручного ввода нулевого слота.

## Причина

При min()-агрегации один незаполненный слот (например W=0, нет оценки Диагноста (DP.ROLE.042)) обнуляет финальный score независимо от значений остальных слотов.

## Правило

При min()-агрегации все слоты должны иметь bootstrap-значение ≥1 до первого реального измерения. Иначе система застревает до принудительного ручного ввода.

## Альтернатива

nan-safe агрегация с игнорированием пустых слотов — но тогда теряется семантика «все слоты обязательны».

## Применимость

Любая система с составными метриками через min(), где слоты могут быть незаполнены при первичном bootstrap.
