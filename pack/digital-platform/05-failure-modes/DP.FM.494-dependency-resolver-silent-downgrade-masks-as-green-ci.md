# DP.FM.494 — Тихий откат резолвера на старую версию

## Механизм ошибки

Несовместимость Node 20 с объявленной версией `wrangler@4.x` привела к фактическому использованию `wrangler@3.90.0` без ошибки установки. Сборки месяцами оставались зелёными, хотя версия инструмента расходилась с ожиданием.

## Диагностический принцип

Успешная установка или сборка доказывает только отсутствие ошибки. Для критичных инструментов CI должен отдельно проверить фактически установленную версию.

## Проверка

«После разрешения зависимостей сравнивается фактическая версия критичного инструмента с ожидаемой?» Нет — совместимость окружения может вызвать незаметный downgrade.

## Границы и связи

Применимо к резолверам, которые могут выбрать другую совместимую версию. `DP.FM.163` описывает шумный отказ из-за stale lock; здесь опасен беззвучный успех с неверным результатом.
