# DP.FM.498 — Свидетель гибели блокирует открытия

**Симптом:** любое `open --housekeeping day-close` отклоняется.
**Причина:** проверка «нет прежнего состояния» не отличает терминальное свидетельство от живого незавершённого состояния.
**Лечение:** игнорировать терминальные свидетельства (fail-closed для неизвестного и симлинков); при повторной гибели — переименовать, не отказывать.
