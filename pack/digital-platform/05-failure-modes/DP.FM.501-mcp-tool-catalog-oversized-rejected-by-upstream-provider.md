# DP.FM.501 — Полный каталог MCP-инструментов отклоняется провайдером модели

## Описание

Полный каталог из 85 инструментов шлюза (~62 КБ описаний) отклоняется вышестоящим провайдером модели при передаче списка инструментов клиенту. После отказа клиент (LibreChat) показывает сервер «подключённым», но с ПУСТЫМ списком инструментов — не ошибкой, а тихой деградацией. Тот же каталог уже ломал двух других клиентов ранее тем же способом — размер каталога стал системным ограничением, а не особенностью одного клиента.

## Симптом

Модель самоотчитывается «у меня нет инструментов» / клиент показывает статус «подключён», но `tools/list` эффективно пуст.

## Порождающая причина

Общий каталог инструментов растёт (85 шт.) без учёта верхней границы размера, которую переносит провайдер модели между шлюзом и клиентом; отказ происходит на этапе передачи каталога, не на этапе вызова конкретного инструмента.

## Диагностический тест

Самоотчёт модели «у меня нет инструментов» — НЕ доказательство отсутствия. Проверять поведенческим тестом: прямая просьба вызвать конкретный инструмент + подтверждение факта вызова (не рассказа о нём).

## Лечение (локальный, реактивный)

Allowlist по точному имени клиента (например, `@librechat/api-client`) — сокращённый список нужных инструментов (23 из 85) с НЕТРОНУТЫМИ описаниями и схемами. Отвергнутая альтернатива: механическая обрезка описаний до N символов — часть описаний несёт обязательные предусловия (например, уточняющий вопрос перед созданием личного пространства), которые обрезка вырежет молча.

## Связь с DP.M.475 (важно: не два факта об одном и том же, а два уровня одной причины)

`DP.M.475` — структурное, проактивное решение той же корневой причины (размер каталога) другим механизмом: поэтапное сокращение набора инструментов по учёту реальных вызовов (телеметрия), а не allowlist по идентификатору клиента. Эта карточка документирует сам отказ (симптом, диагностика, точечный обходной фикс для конкретного клиента); `DP.M.475` — то, что устраняет причину на уровне всего каталога. Применять вместе: симптом здесь подсказывает, когда пора запускать процедуру из `DP.M.475`, а не подменяет её точечным лечением навсегда.
