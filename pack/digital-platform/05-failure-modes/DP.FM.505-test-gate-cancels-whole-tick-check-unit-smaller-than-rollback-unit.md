# DP.FM.505 — Тестовый гейт отменял весь тик из-за одного файла

## Симптом

Автоматическая синхронизация расширений на сервере прогоняет тесты изменённых файлов перед коммитом. Провал теста ЛЮБОГО одного изменённого файла отменял доставку всего набора изменений тика, в том числе файлов, никак не связанных с провалом. По оценке автора capture, за одним упавшим тестом стояли 17-28 несвязанных файлов, и ожидание занимало от 2 до 58 часов (цифры из контекста capture, в коммите не подтверждены).

## Причина

Единица проверки (тест на конкретный файл) и единица отката (весь тик синхронизации) не совпадали: проверка пофайловая, а откат — «всё или ничего» на уровне пакета. Метод DP.M.429 («Структура фикса») описывает именно такой гейт: «провал отменяет весь тик целиком» — это описание после фикса устарело.

Ось отличается от DP.FM.466 (тот же класс инцидентов, тот же скрипт): там тесты падали из-за осиротевших файлов грязного общего чекаута, то есть неверен был субстрат проверки; здесь неверен радиус поражения одного провала, даже при честном провале честного теста.

## Антипаттерн → Паттерн

- **Антипаттерн:** гейт проверяет по одной единице (файл), а откатывает по другой, более крупной (весь тик/коммит) — один локальный сбой блокирует весь пакет.
- **Паттерн:** гранулярность отката сужена до гранулярности проверки: откатывается и повторяется на следующем тике только файл с провалившимся тестом, остальное доставляется; частичная доставка сообщается отдельным классом алерта (`test-gate-partial`), а не молча.

Холодное ревью до деплоя нашло два дефекта самого фикса. Первый: откат восстанавливал файл из индекса git, а не из HEAD, и мог воскресить устаревшее содержимое упавшего предыдущего тика; эталон отката — последнее доставленное состояние (HEAD), не промежуточное. Второй: новый класс алерта самоочищался общей зачисткой каждого тика, обнуляя собственную эскалацию по длительности.

## Тест обнаружения

«Гейт проверяет по единице X, а отменяет по единице Y, более крупной, чем X?» Да → один локальный сбой в X блокирует доставку всех остальных валидных X в том же пакете.
