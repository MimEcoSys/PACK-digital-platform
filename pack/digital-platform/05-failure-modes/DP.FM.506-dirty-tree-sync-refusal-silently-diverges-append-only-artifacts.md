# DP.FM.506 — Защитный отказ на грязном дереве приводит к расхождению append-only артефактов

## Симптом

Фоновая сверка канонической копии репозитория с origin (`canon-reconcile.sh`) отказывается работать при грязном рабочем дереве: это осознанная защита от потери непушенных правок. По контексту capture, в окне 12-25.09 отказали 480 из 484 запусков сверки; Mac-чекаут при этом был грязным 2+ дня (по цитате из коммита: число путей с незафиксированными изменениями выросло с 5 до 103). Локальные только-дописываемые файлы (captures, журналы дня) разошлись с origin: по цитате, 37 уникальных capture-блоков так и не были закоммичены с Mac; по контексту capture, к ним добавились 35 событий журнала дня, а затронутыми были две машины (Mac и сервер). Эти числа и состав затронутых машин взяты из контекста capture, в самом коммите подтверждена только часть.

## Причина

Проверка каждого грязного пути показала: origin «доминирует» везде, кроме аддитивных записей в только-дописываемых файлах, которых больше нигде нет. Защитный отказ при этом не имеет эскалации, пропорциональной длительности (по оценке автора capture, ни эскалации, ни срока; это та же слабость, что описана в DP.FM.444 для частотного подавления алертов, здесь не повторяется как новая). Поэтому «дерево грязное N дней подряд» неотличимо от единичного штатного отказа, а append-only артефакты остаются только локальными.

## Антипаттерн → Паттерн

- **Антипаттерн:** защитный отказ синхронизации, который при бездействии становится постоянным, а для append-only данных ещё и скрывает накопление расхождения.
- **Паттерн:** для append-only артефактов предусмотрен штатный путь аддитивного слияния по идентификатору записи или хэшу payload. В инциденте captures восстановлены сравнением заголовков блоков с полной версией origin и дописыванием недостающих в исходном порядке поверх origin; журналы дня — скриптом `ledger-reconcile.sh` с дедупликацией по хэшу payload (ничего не потеряно, ничего не задвоено).

## Тест обнаружения

«Накапливает ли защитный отказ синхронизации локальные записи только-дописываемых файлов, и есть ли штатное аддитивное слияние по идентификатору записи?» Нет → расхождение растёт молча, пока кто-то не сверит файлы вручную.
