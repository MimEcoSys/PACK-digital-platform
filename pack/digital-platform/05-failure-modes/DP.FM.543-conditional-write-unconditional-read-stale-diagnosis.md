# DP.FM.543 — Условно записанный, безусловно читаемый диагностический файл цитирует протухший диагноз

## Тезис и механизм ошибки

`template-sync.sh` пишет вспомогательный диагностический файл (diffstat + эвристическая догадка «похоже на недоделанную доставку») только в одной ветке кода — когда причина сбоя публикации это «грязное дерево» (dirty tree). Код, который цитирует содержимое этого файла в исходящем алерте, читал его безусловно при ЛЮБОЙ причине сбоя публикации, не только dirty-tree. Если текущий сбой относился к другому классу причин, алерт дословно цитировал диагноз от предыдущего, давно устранённого инцидента dirty-tree — подписанный как объяснение совершенно другого, текущего сбоя. Оба диагноза по формату выглядят одинаково валидными: в алерте нет способа отличить «актуальный диагноз этого сбоя» от «протухший диагноз чужого сбоя».

## Диагностический принцип

Файл-кэш/диагноз, который код обновляет только в ПОДМНОЖЕСТВЕ путей выполнения, но читает во ВСЕХ путях — создаёт разрыв, невидимый по формату: и свежая, и протухшая запись читаются как валидные, потому что проверяется только факт существования файла, а не момент его последнего обновления относительно текущей попытки. Асимметрия «write — для части случаев, read — для всех» — не самостоятельный повод для бага при единственной причине сбоя; становится багом ровно тогда, когда причин сбоя больше одной и они чередуются.

## Границы

Применимо к любому диагностическому/кэширующему файлу, который пишется условно (только в части веток кода), но читается без проверки свежести. Не относится к файлам, которые обновляются на КАЖДОМ прогоне независимо от результата (туда протухание так просто не попадёт) и не относится к файлам, которые читаются только в той же ветке, где записываются.

## Проверка

«Диагностический/кэш-файл обновляется в коде только для подмножества причин/веток, но читается (цитируется в алерте, логе, отчёте) без различения ветки чтения от ветки записи?» Да → проверить наличие явной сверки «файл обновился после начала текущей попытки/прогона» перед использованием содержимого. Нет такой сверки → риск воспроизведения: протухший диагноз от другого инцидента может быть процитирован как причина текущего.
