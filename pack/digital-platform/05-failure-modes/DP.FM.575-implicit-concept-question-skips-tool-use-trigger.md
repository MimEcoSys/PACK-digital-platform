# DP.FM.575 — Неявный вопрос о понятии методологии не вызывает инструмент поиска

## Тезис и механизм ошибки

Модель надёжно вызывает инструмент платформы (MCP) за содержательным ответом только тогда, когда вопрос посетителя явно называет целевую методологию/источник («что такое FPF»). Вопрос про её ключевое ПОНЯТИЕ без явного имени методологии («что такое системное мышление») модель по умолчанию закрывает из собственных общих знаний, не инициируя вызов инструмента — потому что триггер вызова в промпте завязан на распознавание явного ключевого слова/названия, а не на распознавание понятия как такового.

## Диагностический принцип

Триггер вызова инструмента, сформулированный через явное упоминание названия источника в вопросе, по конструкции не покрывает класс вопросов, которые называют ключевое понятие этого источника без его имени — такие вопросы уходят в параметрическую память модели, а не в живой поиск.

## Проверка

«Промпт надёжно вызывает инструмент поиска на вопрос, который называет ключевое ПОНЯТИЕ методологии, но не называет саму методологию по имени?» Нет → воспроизведён DP.FM.575.

## Фикс и границы

Формулировать условие вызова инструмента в промпте через распознавание понятия (семантика вопроса), а не только через совпадение с явным названием источника — не надеяться, что посетитель назовёт методологию по имени. Применимо к любому гостевому/ассистентскому tool-use/RAG промпту с явным keyword-триггером вызова. Не описывает случай, когда вопрос называет источник явно (такой путь работает надёжно) — там инструмент вызывается.
