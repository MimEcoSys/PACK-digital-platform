# DP.FM.639 — Технический контроль репозитория не доказывает разрешение на выдачу содержимого

## Описание

В проекте шлюза материалов рассматривался и был отклонён вариант, при котором владения репозиторием, права записи либо установки приложения достаточно для публикации всего содержимого. Эти признаки подтверждают технические возможности в хранилище, но сами по себе не предъявляют разрешение на выдачу конкретного материала через шлюз.

## Причина и обнаружение

Смешаны два условия: возможность подключить источник и подтверждённое основание выдачи материала. Тест: допускается ли публикация только по признаку repo owner/write/App install без проверки принятого проектом основания для содержимого? Если да, воспроизведён риск этой проектной модели.

## Противодействие и граница

Проверять технический доступ и основание выдачи раздельно, в области конкретного субъекта, материала и операции. Квоты и покрытие вычислений — отдельное условие обслуживания. Это описание отвергнутого проектного решения, не универсальное толкование авторского права и не утверждение о состоявшемся нарушении.

## Связи
