# DP.FM.640 — Одинаковая ошибка не различает неверный путь и отказ доступа

## Симптом и причина

Отрицательная проба доступа получила `Document not found`. Такая же строка возникала при опечатке в пути. Поэтому один ответ не доказывал, что проверяемый механизм действительно отказал по правам: проверка молча предполагала существование объекта по точному адресу.

## Проверка

Точный путь и существование контрольного объекта устанавливаются в разрешённом контексте. Затем проверяется ожидаемый разрешённый доступ и ожидаемый отказ для заранее заданных субъектов и операций. Положительный контроль работоспособности механизма полезен, но сам по себе не устанавливает причину каждого отрицательного ответа. Причина подтверждается доступным аудитом или результатами контролируемой матрицы проверок.

## Граница

Метод не требует раскрывать существование закрытого документа постороннему. Унификация ошибок может быть намеренной защитой. Ошибка испытания — выводить из одной неоднозначной строки корректность разграничения доступа без контроля объекта, пути и субъекта.
