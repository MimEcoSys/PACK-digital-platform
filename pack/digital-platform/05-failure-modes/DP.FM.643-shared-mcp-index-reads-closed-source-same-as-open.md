# DP.FM.643 — Общий индекс выдавал закрытые материалы без требуемого права

## Два датированных свидетельства

17.10.2026 закрытый материал был прочитан через общий индекс под аккаунтом владельца. Это подтвердило доступность материала этому субъекту, но не доказало нарушение прав: разрешение могло следовать из владения. Первоначальный вывод об утечке по этой пробе был снят как недоказанный.

19.10.2026 отдельная проверка под независимым авторизованным аккаунтом вернула закрытые материалы через поиск. Отсутствие у этого аккаунта прав на проверенные источники сверено отдельно через API хостинга. Это свидетельство выдачи без требуемого права в проверенных случаях; оно не доказывает публичный анонимный доступ или охват всех путей выдачи.

Позднее временные патчи закрыли наблюдавшиеся пути выдачи; карточка описывает исторический отказ, а не текущую доступность уязвимости. Переносимый принцип: право получить содержимое проверяется для вызывающего субъекта и операции в каждом пути выдачи индексированной копии; техническое подключение источника не заменяет эту проверку. Полнота исправления требует отдельной сверки путей, не выводится из одной успешной отрицательной пробы.

## Тест обнаружения

Для известного объекта задаются разрешённый и не имеющий права субъекты; их права сверяются независимо в разрешённом контексте. Проверяется выдача через каждый заявленный путь: поиск, чтение и иные пути в границах испытания. Нарушение устанавливается выдачей содержимого субъекту без требуемого права, а не самим фактом чтения владельцем.
