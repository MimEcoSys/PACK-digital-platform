# DP.FM.648 — Исправление действующего экземпляра не охватывает источник новых развёртываний

## Исторический отказ

Действующий хук перевели в режим только чтения, но шаблонная копия продолжала выполнять `git pull --rebase --autostash`. Новое развёртывание из шаблона могло вернуть ранее устранённый опасный путь. Исправление действующего экземпляра действительно полезно, но его охват не включает автоматически источник следующих установок.

## Противодействие

Установить источники развёртывания затронутого компонента и доставить согласованное изменение в каждый необходимый источник. Проверить результат свежей установки из опубликованного шаблона. Несколько репозиториев не образуют атомарный коммит: порядок доставки и оставшееся окно риска фиксируются явно.

## Граница и связи

Это историческое свидетельство; актуальность всех установок здесь не проверялась. DP.FM.369 описывает затирание уже исправленного приёмника, AS.FM.121 — отсутствие обратного канала изменений. Здесь существенен неполный охват исправления источника будущих развёртываний.
