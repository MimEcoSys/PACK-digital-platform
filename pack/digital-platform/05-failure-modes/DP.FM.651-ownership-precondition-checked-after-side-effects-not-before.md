# DP.FM.651 — Проверка владения после побочных действий допускает частично выполненный отказ

## Исторический отказ

В ветке нового WP quick-close несоответствие открытого семафора сессии обнаруживалось на позднем освобождении после работы обработчиков. Запуск успевал произвести побочные действия до отказа по известному предусловию владения.

## Исправление и проверка

В проверенной ветке `cmd_start` с известным вызывающим проверка владения перенесена до создания RUN и запуска обработчиков. Неверное предусловие должно отказать до этих действий; положительная проба должна сохранить штатное выполнение допустимого запуска.

Предварительная проверка не устраняет гонку между проверкой и мутацией. Полномочие должно оставаться действительным и проверяться в точках защищённого изменения по их контракту. Режимы дня/недели без WP имеют отдельные условия: проверка одной ветки не доказывает общий охват всех режимов.

## Связи

DP.FM.508 рассматривает неизвестную идентичность и разрешающий отказ; DP.FM.480 — отсутствие семафора. Здесь известное предусловие проверялось слишком поздно относительно побочных действий.
