# DP.FM.653 — Наличие файла конфигурации подменяет проверку содержимого реестра

## Механизм

Условие «файл существует» не различает корректный пустой реестр и начатую, но не готовую настройку. Отсутствующий и пустой файлы различаются по наличию, но в договоре рассматриваемого опционального реестра дают один исход «не настроено».

## Договор трёх состояний

- Файл отсутствует либо успешно распознан реестр с нулём записей: пропустить гейт с отметкой «не настроен».
- Есть записи, но нет `gate_ready: true`: настройка начата, не завершена; остановить соответствующее действие.
- Есть готовая запись: выполнить обычную проверку гейта.

Ошибка доступа, разбора YAML или неизвестная структура не доказывает ноль записей. Для обязательной защитной конфигурации отсутствие может быть ошибкой: поведение определяется её собственным договором, а не универсальным разрешающим правилом.

## Историческая граница

iwe-local-config `b1d3ee9ed20fe8bd150c23ebb0efe66d0794fdd9` исправляет текст инструкции state-transition gate. Он не доказывает реализацию или исправление машинного парсера.

## Обнаружение

Сверить отсутствующий файл, корректно пустой реестр, записи без готовности, готовую запись и ошибки чтения/структуры с объявленным договором. Это набор требуемых проверок, не заявление о проведённом здесь запуске.
