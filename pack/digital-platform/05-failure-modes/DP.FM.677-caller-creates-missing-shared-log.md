# DP.FM.677 — Вызывающий скрипт создаёт отсутствующий общий журнал вне замка писателя

## Тезис

Если у общего файла есть писатель, который добавляет записи под замком, то создавать отсутствующий файл тоже должен только он и только под этим замком. Любой другой код, выполняющий «если файла нет — создать пустой», работает вне замка и может стереть запись параллельного писателя.

## Механизм

Пять скриптов (day-, week-, month-preclose и недельный оркестратор) содержали блок «если файла журнала нет — записать пустую заготовку». Писатель журнала делает то же, но под `flock`. Между проверкой существования и созданием с усечением параллельный писатель успевал создать файл и добавить первое событие, после чего вызывающий скрипт перезаписывал файл пустой заготовкой. Первое событие терялось.

## Исправление

Замок не добавляется в каждый инициализатор: инициализаторы удаляются. Отсутствующий журнал создаёт только писатель под своим замком. Читатели (например, построитель отчёта) трактуют отсутствие файла как норму — «событий пока нет», а не как ошибку.

## Проверка

Найти в вызывающем коде все места, которые создают или усекают общий файл (`> file`, `cat > file`, запись заготовки), и убедиться, что каждое выполняется под тем же замком, что и добавление записей. Отдельно проверить, что каждый читатель не падает на отсутствующем файле.
