# DP.FM.684 — Кириллический код фазы в английском тексте останавливает символьный гейт

## Симптом

Проверка «Cyrillic gate for en-draft» в Translate Sync отказала: в трёх строках одного английского документа стоял код фазы «Ф21» с кириллической «Ф». В источнике проверены строки `docs/BRANCH-PROTECTION-EMERGENCY.md`; причиной отказа оказался этот символ, а не перевод или CODEOWNERS.

## Механизм

Код фазы перенесли из русского текста в английский без изменения. Символьный гейт ищет кириллицу во всём английском черновике и обнаруживает её также внутри кодов. Гейт сработал по своему правилу; расходятся правило записи кода фазы в переводе и допустимый набор символов черновика.

## Тест обнаружения

«Есть ли в английском черновике коды фаз с кириллическими буквами, которые проверка запрещает во всём тексте?» Да → гейт остановит проверку даже тогда, когда остальной текст переведён.

## Противодействие

Согласовать правило для кодов фаз с символьной проверкой: записывать такой код латиницей (например, `F21`) либо явно предусмотреть исключение для него в проверке. Источник не устанавливает, какой из этих вариантов выбран.

## Границы

Подтверждён один случай: три строки одного документа с кодом `Ф21`. Другие документы, коды и языки по этому источнику не оценены. Запись не утверждает, что гейт неисправен или что какое-либо из двух противодействий уже внедрено.

## Отличие от соседей

- `DP.METHOD.234` описывает символьный барьер публикации; здесь зафиксировано расхождение между правилом записи кода фазы и этим барьером.
- `DP.FM.680` описывает обработку Unicode утилитой `tr`; здесь проверка кириллицы срабатывает корректно.
