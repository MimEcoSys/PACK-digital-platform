# DP.FM.698 — Отклонённый коммит оставляет чужой HEAD

## Симптом

Закрытие сессии отказывает: в заявленных коммитах числится чужая работа, снять заявку нельзя.

## Причина

Заявка «мой коммит = HEAD» делалась без проверки успеха commit. Хук отклонил коммит, верхним остался чужой.

## Исправления

1. Коммит заявляется только после подтверждённого успеха.
2. Заявку на коммит, не меняющий ни одного заявленного файла сессии, разрешено снимать — в том числе когда коммит уже опубликован. Это уточняет DP.FM.569 (раздел «Текущий статус»): там отказ снятия при доказательстве публикации оставался без исключения.

## Семейство «атрибуция по окружению, а не по факту»

Ещё два случая: файлы заявлялись из корневого каталога и приписывались не тому репозиторию (см. DP.FM.561); публикация без номера сессии не писала квитанцию.
