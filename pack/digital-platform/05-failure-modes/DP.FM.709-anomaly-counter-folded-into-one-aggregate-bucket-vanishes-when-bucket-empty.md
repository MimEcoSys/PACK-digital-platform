# DP.FM.709 — Счётчик отбракованных входов, вложенный в одну группу сводки, исчезает с пустой группой

## Симптом

Партия из вчерашних записей плюс одна нераспознанная строка давала сводку без предупреждения о нераспознанной строке. Поймано холодной проверкой, закреплено тестом «yesterday-plus-garbage».

## Механизм

Сводка делит записи на группы по признаку (дата: «сегодня», «вчера»). Счётчик аномалий (нераспознанные записи) выводился внутри одной группы, «за сегодня». Но у нераспознанной записи этого признака нет: она не несёт своей даты, и честно отнести её к группе нельзя. Когда группа «сегодня» пуста, её блок не печатается, и предупреждение пропадает вместе с ним.

## Принцип

Сообщение об отбракованных входах не должно зависеть от того, какие группы отчёта непусты. Запись без признака группировки выводится вне групп, отдельной фразой.

## Лечение

Вывести счётчик аномалий из блоков групп на уровень всей сводки. Регрессионный тест: входы только из неосновной группы плюс одна аномальная запись; предупреждение должно остаться.

## Тест обнаружения

«Есть ли в сводке счётчик или предупреждение, которое печатается внутри блока группы? Может ли аномальная запись прийти в партии, где эта группа пуста?» Оба «да» → предупреждение может потеряться.

## Граница

Не о дедупликации и не о различии «новое / присутствующее в партии» (DP.M.472, раздел «Семантика счётчиков»). Здесь вопрос в том, к какой группе вообще можно отнести запись без признака группировки. Прецедент один.
