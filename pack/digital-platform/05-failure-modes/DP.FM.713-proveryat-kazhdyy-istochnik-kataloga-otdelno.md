# DP.FM.713 — Проверять каждый источник каталога отдельно

## Правило

В агрегированном каталоге проверять получение данных от каждого источника, применённые права и состояние его кэша отдельно. Успех одного инструмента или общий ответ состояния не доказывают доступность другого; причину сбоя устанавливать по соответствующему пути.

Пример реализации: шлюз отвечает сам, а каталог отдельного backend при сбое получения оказывается пустым; его кэш хранится 120 секунд с ключом по имени backend. Подписку в этой версии проверяют при вызове, поэтому её отсутствие не доказывает причину отсутствия инструмента в списке. Длительность кэша и место проверки подписки относятся к этому примеру, не задают общую норму.

## Проверка применения

Один источник отвечает, другой не отдаёт каталог — общий успех не скрывает частичный отказ.
