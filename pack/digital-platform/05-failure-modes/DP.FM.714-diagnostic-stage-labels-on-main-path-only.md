# DP.FM.714 — Диагностические метки стадий стоят только на основном пути

**Симптом.** Из 21 аварийной остановки обычных публикаций за 20 ч причина видна у 9. Путь `--expected-base` отбрасывает stderr ребёнка и обходит обёртку меток, поэтому у 12 из 21 меток нет.

**Причина.** Инструментирование добавлено в основную ветку исполнения, альтернативные ветки остались без него.

**Побочная ловушка.** У метрики времени не зафиксировано начало отсчёта: `hold_s` выше потолка не означает опоздание сторожа, потому что `HOLD_START` стоит до подготовки, а таймер ребёнка стартует позже.

**Профилактика.** Инструментировать каждую ветку исполнения; для метрики времени явно записывать, от какого события идёт отсчёт.
