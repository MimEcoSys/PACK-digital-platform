# DP.FM.717 — Пустая переменная каталога: запись в текущий каталог

## Симптом

Смоук-тест `session-close-feeder-key-smoke.sh` оставлял файлы состояния в текущем каталоге рабочей копии. Тест при этом мог проходить: запись удавалась, просто не туда.

## Причина

Путь к файлам состояния строился из переменной каталога. При пустой `STATE_DIR` он стал относительным, и запись ушла в каталог, откуда запущен скрипт, то есть в рабочую копию репозитория. Точная форма склейки в исходнике при формализации не проверялась. Строка `"$STATE_DIR/файл"` при пустом значении даёт `/файл` (корень ФС), а склейки вида `"${STATE_DIR}файл"`, `"$STATE_DIR${STATE_DIR:+/}файл"` или передача пустого каталога в `cd`/`mktemp -p`/`os.path.join` дают путь от cwd. Исход в любом случае одинаковый: запись не туда, без ошибки.

`set -u` не защищает: переменная может быть задана пустой строкой (например, `STATE_DIR="$(mktemp -d …)"` при сбое команды или пустое значение из окружения). `set -e` тоже молчит, потому что запись успешна.

## Антипаттерн → Паттерн

- **Антипаттерн:** обязательный каталог берётся из переменной без проверки, первая запись идёт сразу.
- **Паттерн:** до первой записи проверить обязательные пути: `: "${STATE_DIR:?STATE_DIR is empty}"` или явный `[ -n "$STATE_DIR" ] || { echo FAIL; exit 1; }`. Для тестов и скриптов с побочной записью дополнительно проверять, что путь абсолютный и указывает внутрь ожидаемого корня (временного каталога теста).

## Тест обнаружения

Запустить скрипт с `STATE_DIR=""` из чистого временного каталога. Если в cwd появились файлы или скрипт завершился успешно, дефект воспроизведён. Ожидаемое поведение: FAIL до любой записи.

## Отличие от смежного

- DP.FM.561, DP.FM.613: путь изначально относительный или резолвится относительно cwd. Здесь путь задуман абсолютным и становится относительным из-за пустого префикса.
- DP.FM.480: пустой обязательный контекст расширяет область проверки. Здесь пустой обязательный путь переносит место записи. Класс один: пустой обязательный вход должен давать отказ, а не молчаливый дефолт.
- VR.FM.010: окружение оператора просачивается в тест. Здесь тест просачивается в рабочую копию.
