# DP.FM.725 — Пропуск по хешу оставляет старое время изменения, и проверенный индекс выглядит устаревшим

## Симптом

Сигнал свежести показывал, что граф понятий паков «не обновляется с 04.09». Ночной обход при этом шёл каждую ночь. Разбор Codex в пир-сессии 2026-11-03 показал: файлы не менялись, обход их пропускал, и возраст узлов не обновлялся.

## Механизм

1. Индексатор оптимизирован: если хеш содержимого совпал с сохранённым, файл пропускается и узел не переписывается.
2. Время изменения узла обновляется только при перезаписи. При пропуске оно остаётся прежним.
3. Сигнал возраста («давно ли обновлялся граф») считается по времени изменения узла.
4. Одна отметка отвечает на два разных вопроса: «когда содержимое изменилось» и «когда его последний раз сверили с источником». Пропуск по хешу правильно не трогает первое, но тем же действием теряет второе.
5. Итог: чем стабильнее источник, тем «старее» выглядит исправно проверенный индекс. Сигнал устаревания срабатывает ежедневно и перестаёт отличать проверенное неизменное от непроверенного.

## Почему опасно

Ложный сигнал устаревания приучает его игнорировать. Когда обход действительно перестанет работать, картина будет та же, что при исправном обходе неизменного источника. Обратная попытка «лечить» обновлением времени изменения при каждом пропуске сломает другой потребитель: того, кому нужно знать, когда содержимое менялось.

## Лечение (направление)

- Хранить две отметки: «когда проверено» (обновляется при каждом обходе, включая пропуск по хешу) и «когда изменилось» (только при смене содержимого).
- Сигнал «обход не работает» считать по отметке «когда проверено», сигнал «содержимое давно не менялось» — по «когда изменилось», и не смешивать их в одном показателе.
- Регрессионная проверка: прогон обхода на неизменном источнике — «когда проверено» сдвигается, «когда изменилось» нет.

Починка на момент захвата не описана; пункты — направление из разбора, не проверенная реализация.

## Тест обнаружения

«Пропускает ли обход неизменившиеся объекты, и по какой отметке считается возраст?» Если пропуск не обновляет отметку, по которой считается возраст, — сигнал устаревания ложный для любого стабильного источника.
