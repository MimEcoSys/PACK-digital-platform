# DP.FM.742 — Подсчёт строк таблицы «строки с `|` минус 2»: вторая таблица ломает счёт и понижает класс отказа

## Симптом

Проверка секции, заполненной одними заглушками, выдаёт мягкое предупреждение вместо фатального отказа, если в секции несколько таблиц.

## Механизм

Счётчик «все строки с вертикальной чертой минус два» предполагает ровно одну таблицу. При второй таблице он включает её заголовок и разделитель в строки данных. Число данных оказывается завышенным, хотя новых содержательных строк нет.

В исходном диффе **обе** проверки использовали одинаковый неверный подсчёт. При завышенном числе строк условие «все строки — заглушки» не выполнялось, а условие «наряду с заглушками есть данные» выполнялось. Ошибку вызывает неверное распознавание структуры, а не расхождение чисел между двумя проверками.

## Противодействие

1. Распознавать заголовок и разделитель каждой таблицы, а не вычитать константу для всей секции.
2. Задать единое определение строк данных для всех проверок строгости. Общая функция или один заранее вычисленный набор уменьшают риск последующего расхождения.
3. Проверять секцию с одной таблицей, несколькими таблицами и смесью реальных строк с заглушками.

В коммите `51305f66b` одинаковый структурный разбор на awk добавлен в два места. Вычисление набора один раз — рекомендация карточки, а не утверждение о реализации этого коммита.

## Проверка

Добавление второй пустой таблицы с заголовком и разделителем не должно увеличивать число строк данных и смягчать отказ. Добавление настоящей строки должно изменить вердикт согласно контракту. Проверку выполняют на тех реализациях awk, для которых заявлена поддержка.

## Отличие от соседей

- DP.FM.568: парсер не распознаёт вариант маркера списка; здесь распознанные служебные строки ошибочно засчитываются как данные.
- DP.FM.054: проверка метаданных не проверяет структуру тела; здесь структурная проверка существует, но неверно считает строки.
- DP.FM.362: совпадение в произвольной ячейке выдаётся за нужную структуру; здесь ошибка счёта заголовков и разделителей.

- DP.FM.473: фиксированный индекс выбирает не ту колонку после изменения её позиции. Здесь колонки могут оставаться прежними: добавление второй таблицы нарушает постоянное вычитание числа заголовочных строк. Общее — скрытое структурное предположение; отказ и способ проверки различаются.
