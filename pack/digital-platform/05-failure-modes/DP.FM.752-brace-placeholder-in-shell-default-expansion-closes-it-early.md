# DP.FM.752 — Метка `{{X}}` в слове по умолчанию `${VAR:-…}` закрывает раскрытие раньше времени

## Симптом

Правка дефекта DP.FM.751 добавила в навыки запасной путь:

```bash
${IWE_SCRIPTS:-${IWE_TEMPLATE:-{{IWE_TEMPLATE}}}/scripts}/lib
```

Результат при всех трёх сочетаниях (воспроизведено в GNU bash 5.2.37 и macOS bash 3.2.57):

| Переменные | Результат |
|---|---|
| обе не заданы | `{{IWE_TEMPLATE}/scripts}/lib` |
| `IWE_TEMPLATE=/x` | `/x}/scripts}/lib` |
| `IWE_SCRIPTS=/s` | `/s}/scripts}/lib` |

Путь сломан даже тогда, когда нужная переменная задана.

## Механизм

1. В `${VAR:-word}` bash ищет закрывающую `}` раскрытия. Открывающие `{` из `{{` в слове по умолчанию не учитываются как парные, а первая встреченная `}` закрывает раскрытие.
2. Поэтому `${IWE_TEMPLATE:-{{IWE_TEMPLATE}` — законченное раскрытие, а оставшиеся `}}` и `/scripts}` становятся литеральным текстом после него.
3. Литеральный хвост дописывается к любому значению, поэтому от того, заданы ли переменные, поломка не зависит.
4. Автор проверял конструкцию с заглушкой без фигурных скобок. На ней раскрытие разбирается правильно, и проверка прошла.

## Диагностика

- Прогонять **строку из файла как есть** (копированием, а не перепечаткой и не упрощением) по матрице: ни одна переменная не задана / задана одна / заданы обе. Сравнивать с ожидаемым путём.
- Признак: в результате есть `}`, а в ожидаемом пути её нет.

## Лечение

- Не класть фигурные скобки, в том числе метки шаблона `{{X}}`, в слово по умолчанию `${VAR:-…}`. В источнике запасной путь заменён литералом без скобок (`$HOME/IWE/FMT-exocortex-template`), как в остальных навыках.
- Если метка в этом месте нужна, раскрыть её до попадания в shell (подстановкой установщика) — с учётом области подстановки, см. DP.FM.751.

## Границы

- При применении 12.11.2026 воспроизведено также в macOS bash 3.2.57; поведение zsh и dash не проверялось.
- Общий урок про «проверку на упрощённой копии» здесь показан на одном случае. Карточка не претендует на отдельный метод проверки.
