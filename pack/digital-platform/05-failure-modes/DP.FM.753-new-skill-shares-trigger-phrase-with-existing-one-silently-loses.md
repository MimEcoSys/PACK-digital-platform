# DP.FM.753 — Новый навык с той же фразой-триггером молча проигрывает существующему

## Симптом

В шаблон добавили навык лёгкого онбординга для новичка без подписки с триггером «с чего начать?». Холодная проверка нашла, что ту же фразу уже обслуживал навык диагностики, который работает через подписку. Пользователь без аккаунта, сказав «с чего начать?», попадал бы в подписочный сценарий. Обещание «без подписки» нарушалось бы без всякой ошибки: каждый навык по отдельности исправен.

## Механизм

1. Навыки агента выбираются по естественно-языковому совпадению фразы пользователя с описанием или списком фраз навыка.
2. Автор нового навыка проверяет, что его навык срабатывает на фразу, но не проверяет, какие ещё навыки срабатывают на неё же.
3. При пересечении выбор между навыками не задан явно и зависит от модели и порядка загрузки. Новый навык может проигрывать, и это не видно ни в одном отдельном тесте.
4. Переформулировка фразы не решает задачу: пользователь говорит естественными словами, и любая близкая фраза снова попадёт в пересечение.

## Диагностика

При добавлении навыка или изменении его триггеров:

- Найти все навыки, описания или фразы которых срабатывают на те же формулировки (поиск по `triggers.phrases` и описаниям, плюс прогон самих фраз в чистом контексте).
- Для каждого пересечения ответить: какой навык должен сработать у какого пользователя? Если ответ зависит от состояния пользователя, это состояние должно стоять в условиях навыков.

## Лечение

Разводить навыки по **условию применимости** (состоянию пользователя или среды), а не по тексту фразы. В источнике у навыка диагностики появилось предусловие «пользователь вошёл аккаунтом МИМ». Вне этого условия он себя не предлагает, и фраза остаётся за онбордингом.

## Границы

- Наблюдение одно (FMT-exocortex-template, два навыка). При применении 12.11.2026 развод по состоянию подтверждён в текстах навыков; детерминированный алгоритм выбора навыка в конкретной среде (Claude Code и другие) не исследовался.
- Карточка не про случай, когда навык не срабатывает вовсе (DP.FM.575).
