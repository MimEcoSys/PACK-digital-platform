# DP.FM.781 — Позиционный код понятия уносит чужие атрибуты

## Симптом

Переводчик показывает у понятия чужое английское имя: у «неудовлетворённости» стоит название руководства. Отметка «проверено» тоже относится к прежнему слову.

## Механизм

1. Загрузчик графа выдаёт коды по порядку обхода файлов источника.
2. Атрибуты (английское имя, статус проверки) привязаны к коду, а не к устойчивому ключу понятия.
3. Любое изменение состава или порядка файлов сдвигает коды: код переходит к другому слову, атрибуты остаются — тихая порча без ошибки.
4. Порча видна в конечном потребителе (Переводчик), а причина — выше по цепочке, в загрузчике.

## Лечение

1. Устойчивые коды, выведенные из ключа самого понятия, а не из позиции при обходе.
2. Перенос или перенумерация старых кодов — только с явным журналом «было/стало», не молчаливым сдвигом привязки.
3. (Вывод, в источнике не проверялся.) После переноса перепроверить атрибуты, унаследованные по старому коду.

## Диагностика

Неверное имя в выдаче → искать источник выше по цепочке (загрузчик, генератор кодов), а не в потребителе, где порча стала видна. Вывод, в источнике не проверялся: меняется ли код понятия, если добавить файл в начало обхода?
