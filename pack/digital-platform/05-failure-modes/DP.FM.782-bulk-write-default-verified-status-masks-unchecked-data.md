# DP.FM.782 — Массовая запись по умолчанию ставит «проверено»

## Симптом

В словаре английских имён понятий 194 из 495 строк негодны, хотя все помечены как проверенные.

## Механизм

1. При массовой загрузке поле статуса по умолчанию получало «ок».
2. Новые значения сразу записывались с «ок», без человека.
3. Судя по принятому лечению, при обновлении значения статус и происхождение не обновлялись вместе с ним (прямого наблюдения в источнике нет).
4. Поле совпадает с фактом записи, а не с фактом проверки, и перестаёт нести информацию.

## Лечение

1. Новое значение по умолчанию — «на проверку», не «ок».
2. Обновление значения меняет вместе с ним отметку происхождения и статус.
3. Уже массово одобренные записи перепроверить отдельным проходом.

## Диагностика

Вывод, в источнике не проверялся: сколько записей получили «проверено» одной операцией? Есть ли у статуса автор проверки, отличный от загрузчика?

## Границы

Один источник данных (граф понятий, РП-620). Правило переносимо на любой реестр со статусом проверки, заполняемый пакетной операцией.

## Связи

- `DP.FM.781`, `DP.FM.783` — другие пути порчи имён в том же графе.
