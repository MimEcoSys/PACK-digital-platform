# DP.FM.783 — Подстановка кода вместо пустого имени маскирует пропуск

## Симптом

В поле английского имени понятия стоит его код. Строка выглядит заполненной и проходит проверку «имя есть».

## Механизм

1. Массовое преобразование при пустом входе (русское имя пусто) берёт запасное значение — код понятия.
2. Отсутствие данных превращается в правдоподобное значение.
3. Проверки и потребители ниже по цепочке не отличают настоящее имя от подстановки: пропуск невидим там, где его проще всего поймать.

## Лечение

Пустой вход массового преобразования даёт явный пропуск записи со списком затронутых строк или явную ошибку. Подстановку кода в поле, предназначенное для человека, не делать.

## Диагностика

Вывод, в источнике не проверялся: совпадает ли значение поля с кодом или ключом записи? Простой запрос «имя = код» находит все подстановки.

## Границы

Один источник (скрипт массового перевода, РП-620).
