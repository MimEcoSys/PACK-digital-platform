# DP.FM.791 — Посредник между диалектами API модели, переводящий только текст, молча лишает клиента инструментов

## Симптом

Бот консультаций (пилотный и боевой) ни разу не вызвал инструмент. Ответы выглядели обычными, но строились из памяти модели, а не из данных инструментов. Ошибок в журналах не было.

## Механизм

Бот шлёт шлюзу запрос в форме Anthropic: определения инструментов, блоки `tool_use` и `tool_result`. Шлюз пересылал его в LiteLLM `/chat/completions` (форма OpenAI) и переводил только текст сообщений.

- Определения инструментов уходили нетронутыми и для модели в форме OpenAI не существовали.
- Если модель всё же возвращала `tool_calls`, шлюз их отбрасывал.
- `finish_reason: "stop"` передавался как `stop_reason`, то есть «ход закончен».

Цикл инструментов бота видел обычный завершённый ответ и выходил. Каждое звено по отдельности работало без ошибок.

## Почему опасно

Непереведённое поле не даёт ошибки: оно пропадает. Результат правдоподобен, и проверка «ответ пришёл» проходит. Потеряна целая способность клиента, но ни код ответа, ни журнал этого не показывают. В DP.FM.734 шлюз с тем же дефектом (срезал массив инструментов) давал видимый отказ («502»); тихая деградация опаснее, потому что её никто не ищет.

## Лечение

Из источника (коммит 7c16689): перевод в обе стороны.

- Запрос: инструменты → функции; `tool_choice` переводится; `tool_use` → `tool_calls`; `tool_result` → сообщение `role=tool`.
- Ответ: `tool_calls` → блоки `tool_use`; причины остановки сопоставлены явно (`stop`→`end_turn`, `tool_calls`→`tool_use`, `length`→`max_tokens`).
- Аргументы, пришедшие не объектом, сохраняются под `_raw_arguments`, а не теряются.
- 9 тестов на перевод.

Переносимое правило (обобщение, не из исправления): посредник между диалектами API перечисляет все типы блоков и все причины остановки обеих сторон и для каждого решает явно — перевести или отклонить с ошибкой. Молча терять поле нельзя. Само исправление `7c16689` пропускает как есть сообщения, в которых блоков инструментов нет: «как есть» допустимо там, где форма в обоих диалектах совпадает, и это решение должно быть записано, а не случайным.

## Тест обнаружения

«Есть ли в приёмке посредника сквозной ход, где модель вызывает инструмент, клиент исполняет его и получает итоговый ответ?» Нет — приёмка проверяет только текст, и потеря инструментов останется невидимой.

«Для каждого типа блока и каждой причины остановки исходного диалекта: куда он переводится?» Пустая клетка — место молчаливой потери.
