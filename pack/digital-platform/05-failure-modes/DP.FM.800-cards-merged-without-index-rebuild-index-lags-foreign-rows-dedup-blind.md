# DP.FM.800: Карточки сливают без пересборки оглавления и карты пака

## Механизм отказа

Оглавление пака (`00-pack-manifest.md`) и карта (`07-map/DP.MAP.001.md`) собираются генератором из шапок карточек. Карточку же можно слить в основную ветку отдельным коммитом, не пересобрав их. Тогда перечень отстаёт от основной ветки, и отставание копится незаметно, пока его не вскроет одно из двух событий:

1. **Следующая пересборка тянет чужие строки.** Генератор строит перечень по всему текущему состоянию пака, а не по изменению сессии. Первый, кто пересоберёт оглавление, получит в своей правке строки всех карточек, слитых до него без пересборки.
2. **Поиск дублей по оглавлению слеп к свежим карточкам.** Повторы ищут по оглавлению и карте; карточки без строк там не находятся, и новая карточка-дубль проходит проверку.

Ручная дозапись строк чинит отставание лишь частично: она расходится с форматом генератора и при следующей пересборке строки меняются.

## Прецеденты

**10.11.2026, PR #61.** Коммиты 281c42d (DP.FM.730–741) и 2c41caf (DP.M.600–611) слили в основную ветку 24 карточки без пересборки: оба коммита содержат только файлы карточек. В тот же день PR #61 (РП-616, роли двух новых подсистем, коммит 1e89350) пересобрал оглавление и карту для двух своих карточек ролей; генератор заодно добавил 24 строки чужих карточек и ничего не удалил. Автор PR назвал это в описании коммита («also picks up DP.FM.730-741 and DP.M.600-611 added earlier today; no rows dropped»).

**18.11.2026, пакет 27 РП-170.** В оглавление и карту не были внесены карточки, начиная с DP.FM.754 и DP.M.615: не хватало 56 строк, поэтому поиск повторов по этим указателям свежих карточек не видел. Первая ручная дозапись нарушила формат: колонка названия взята из `name_ru`, а не из `name`, текст обрезан посреди слова; в шапке карты устарела статистика, хотя файл помечен «Do not edit manually». Строки дописаны (86e93fc); тем же днём по проверке Fable дописаны ещё 12 строк других видов карточек (7ec7823), сверка покрытия показала 0 карточек без строк в указателях. Вечером того же дня строки двух следующих пакетов снова дописывали руками, потому что `generate-map.py` не разбирает DP.SC.173 (сообщения коммитов 3f06fb2, d9e953b).

## Причина

Перечень отставал от основной ветки: слияние карточки не требовало пересборки оглавления и карты. Совпадение по времени с параллельной работой лишь вскрыло отставание, а не создало его: к моменту PR #61 чужие карточки уже лежали в основной ветке.

## Тест обнаружения

- После пересборки в правке есть строки карточек, которых правка не трогала, → перечень отставал от основной ветки.
- Число карточек с `id` в папках пака больше числа строк оглавления или карты → поиск дублей по ним неполон.

## Что делать

1. Собирать оглавление и карту программой из самих карточек, а не дописывать строки руками (захват 18.11).
2. Пересобирать указатели тем же изменением, которое добавляет карточку, чтобы перечень не отставал от основной ветки.
3. После пересборки сверить, что строки не удалены.
4. Перед поиском дублей по оглавлению сверить покрытие: у каждой карточки с номером есть строка в обоих указателях.

## Наблюдение (не сбой)

Назвать в описании PR строки, которые пересборка добавила не от автора правки, полезно для проверяющего; в PR #61 это сделано. Это смягчает следствие, но не устраняет отставание.

## Граница

Два проявления в одном паке, 10.11 и 18.11. По захвату 18.11 скрипт оглавления обобщён на все виды карточек; в истории PACK-digital-platform видны дозапись строк и сверка покрытия (86e93fc, 7ec7823), а коммит самого скрипта в этой записи не найден и не проверялся. Обязательная пересборка при слиянии карточки (проверка или хук) в источниках не описана.
