# Две ветки берут один свободный номер

## Механизм отказа

Две сессии независимо дописывают один нумерованный перечень. Каждая выбирает следующий свободный номер на момент ветвления; обе корректны локально, но после слияния номер двойной.

## Прецедент

11.11.2026 потребность наставника получила номер 104 в запросе №67, а параллельный запрос №66 занял 104 под табло отправок бота. Оба запроса слиты; запрос №69 перенумеровал потребность наставника в 105.

## Противодействие

По итогам разбора: сверять свободный номер с опубликованной веткой непосредственно перед слиянием и проверять уникальность после него. Повторная сверка сужает окно гонки между проверкой и слиянием, но не устраняет его.

## Тест обнаружения

«Могли ли две ветки выбрать один номер между ветвлением и слиянием, и подтверждена ли уникальность в итоговой опубликованной версии?»
