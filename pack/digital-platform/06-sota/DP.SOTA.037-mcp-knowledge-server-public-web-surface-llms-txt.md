# DP.SOTA.037 — Публичная веб-поверхность MCP-сервера знаний

## SoTA-статус

**Current** (актуальность сравнения); зрелость самой карточки — draft (одна реализация, WP-581 Ф2). MCP-сервер знаний (mcp.system-school.ru) получил человеко- и LLM-читаемую веб-поверхность поверх протокола MCP: карта маршрутов строится один раз при загрузке бандла по нормализованному pathname, многочастные страницы гайда собираются по порядку и отдаются как простой текст по стабильным путям.

## Сравнение с отраслевой практикой

- **llms.txt.** Конвенция сообщества: файл `/llms.txt` в корне сайта как точка входа для ИИ-агентов, `/llms-full.txt` — расширенный вариант. Платформа следует конвенции: оба файла генерирует сборщик бандла и они покрывают только страницы гайда, не весь корпус. Файлы генерируются из того же бандла, что и страницы гайда.
- **Страницы как text/plain.** Обычная отраслевая практика для агентского чтения: отдавать содержимое без HTML-разметки. Платформа делает так же по путям `/go/<slug>`; новое по сравнению с типовым решением здесь только атрибуция.
- **Атрибуция источника.** Ссылка `/go/<slug>?src=<источник>` ставит cookie атрибуции только для источников из белого списка; неизвестный `src` cookie не ставит, без тихой подмены на значение по умолчанию («web»): отсутствие данных не маскируется правдоподобным, но неверным значением. Каждый MCP-ответ несёт `privacy_note` в metadata.

Внутренний урок ревью («сгенерировано ≠ закоммичено»: сгенерированные `llms.txt` и `llms-full.txt` не были закоммичены, и свежий чекаут упал бы при старте всего процесса) сам по себе относится к классу ошибок, а не к SOTA; проверка перед выкладкой — тесты плюс `curl` по каждому новому маршруту в реальном контейнере.

## Применимость

Любой MCP-сервер знаний или инструментов, которому нужна параллельная человеко- и агент-читаемая веб-поверхность: белый список атрибуции без fallback-значения, llms.txt как конвенция обнаружения, генерация этих файлов из бандла.

## Revision criterion

Пересмотреть карточку, если: (1) llms.txt заменится или будет дополнен признанным стандартом обнаружения контента для ИИ-агентов (например, на уровне протокола MCP); (2) появится признанная практика атрибуции источника для агентского трафика, отличная от cookie по белому списку; (3) реализация платформы выйдет за страницы гайда на весь корпус.
