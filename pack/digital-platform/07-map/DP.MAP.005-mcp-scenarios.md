# [DP.MAP.005] Сценарии MCP

> **Назначение:** одно место, где видно, что человек делает с MCP платформы, какие инструменты (tools) это обеспечивают, в каком состоянии это сейчас и куда пойдёт при разделении MCP. Срез на 31.10.2026. Составлено по закрытым карточкам рабочих продуктов (РП); истина по каждой работе остаётся в них.

## Как читать

- **Блок** (заголовок «Кто») - роль человека и его доступ: без аккаунта, с аккаунтом без подписки, с подпиской МИМ, с подпиской Aisystant. Внутри блока все сценарии этой роли; большие блоки разбиты на темы.
- **Строка** - один сценарий: что делает человек и что получает в итоге. Сценарии из прежних каталогов сохраняют свои коды в скобках (С3, О6, Г2, Open 1.3); одинаковый код у разных сценариев различается буквой.
- **Где** - в каком клиенте это происходит (claude.ai, веб-ChatGPT, Codex, Claude Code, LibreChat, бот и другие).
- **Что делает / Что получает** - действие человека и результат для него. Если платформа при этом что-то фиксирует, это записано в той же ячейке после слов «Платформа фиксирует».
- **Инструменты (Tools)** - все инструменты MCP, на которых держится сценарий. Названия на английском даны как в MCP; если имени нет (подключение клиента, плагин, страница), написана суть текстом.
- **Текущее состояние** - работает, частично работает, не работает, нет в системе (сценария ещё нет), не проверено (свидетельства нет). «Работает» ставится только при живом запуске, коде или описи.
- **Подтверждено** - чем доказано состояние: живой запуск, код, опись, заявлено; дата; на каком MCP получено. «Заявлено» - так написано в карточке, но своего запуска нет.
- **Куда** - в какой MCP пойдёт сценарий: Open Aisystant, Open МИМ, `mcp.aisystant.com/mcp`, новый Aisystant MCP; «остаётся в `mcp.aisystant.com/mcp`» - в новый не берём; «вне платформы» - отдельный личный сервер; «не определено» - записи нет, это не решение «никуда». Если инструменты одного сценария идут в разные MCP, записаны пары «MCP: инструменты».
- **Решение** - пилот решил; предложение агента (не утверждено); решения нет; смешанный (часть решена, часть нет, см. примечание).
- **РП и чего ждёт** - внутренний рабочий продукт и его этап (Ф) в скобках, и что блокирует. Карточки РП закрыты, поэтому в таблице это только метка.

### Слова, которые встречаются

- **MCP** - программа-сервер, через которую ИИ-клиент вызывает инструменты платформы.
- **Инструмент (tool)** - одна функция MCP: например, поиск или чтение документа.
- **Клиент** - программа, где человек общается с ИИ: claude.ai, веб-ChatGPT, Codex, Claude Code, LibreChat, Telegram-бот.
- **РП, Ф** - рабочий продукт (внутренняя единица работы) и его этап (фаза).
- **Опись** - проверка списка и чисел нынешнего MCP от 29-30.10; повторно не снималась.
- **Живой запуск** - вызов или прогон с датой, который кто-то реально видел.
- **Охранное правило** - требование «ИИ не делает X», записанное как сценарий человека.
- **Онбординг** - первое знакомство человека с платформой.
- **Ступень, диагностика** - уровень мастерства участника и проверка, которая его оценивает.
- **Чек-лист** - перечень фактов о пути участника.
- **Табло** - страница наставника с состоянием группы.
- **Open** - открытые MCP без подписки.
- **Плагин** - подключение MCP из каталога клиента (OpenAI, Claude).
- **OAuth** - вход через аккаунт без передачи пароля клиенту.
