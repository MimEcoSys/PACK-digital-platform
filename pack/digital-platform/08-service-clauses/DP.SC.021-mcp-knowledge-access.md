# [DP.SC.021] Свои знания в ИИ-клиенте через сервер МИМ с подпиской (Россия)

## Обещание

**Кому:** человеку с действующей подпиской МИМ, который добавил сервер MIM MCP (сейчас адрес `mcp.aisystant.com/mcp`) в свой ИИ-клиент.

**Обещанный исход** (проверено 08.11.2026 на одной учётной записи с подпиской):
- поиск по личным материалам возвращает документы его подключённых личных источников;
- чтение цифрового двойника возвращает его профиль;
- проверка учётной записи показывает его подписку.

**Границы доступа:**
- без входа — отказ;
- вход без подписки — личные материалы и цифровой двойник: отказ; знания платформы: доступны. Это правило подписки (DP.SC.112); живой проверкой на учётной записи без подписки пока не подтверждено — см. «Как проверить».

**Переходное условие (решение пилота 05.11.2026, подтверждено 08.11.2026).** Пока открытый сервер Open МИМ (`open.system-school.ru/mcp`) не отвечает, этот же сервер отдаёт и знания платформы (паки, руководства). Когда Open МИМ начнёт отвечать, знания платформы исключаются из этого обещания отдельной правкой — с предупреждением подписчикам и «да» пилота.

**Держит:** владелец РП-560 (MIM MCP).

**Время отклика:** не задано; назначается при переводе из черновика в действующее.

**Режим отказа:** не задано; назначается при переводе из черновика в действующее.

## Что не входит в обещание

- Удобство и число шагов подключения: выдача пропуска через бота — DP.SC.190; подключение по умолчанию в шаблоне IWE — РП-610.
- Запись в цифровой двойник — не проверялась; вернётся отдельной строкой после своей проверки.
- Работа в конкретном или «любом» ИИ-клиенте сверх того, на котором проверено.
- Знания без аккаунта — предмет открытых серверов (Open Aisystant, Open МИМ); их обещание в паке ещё не записано (ближайшие — DP.SC.168 в открытой части и DP.SC.203).
- Подписчики Aisystant Corp (мир) — DP.SC.223.
- Репозитории и источники, которые человек не подключил.

## Как проверить

Критерий перевода из черновика в действующее (формат 07.11: что меряем, цель, откуда берём, кто отвечает):

| Что меряем | Цель | Откуда берём | Кто отвечает |
|---|---|---|---|
| Запрос к серверу без учётных данных | отказ (401) | проверка 08.11.2026; повтор на дату перевода | владелец РП-560 |
| Учётная запись с подпиской: поиск личных материалов, чтение двойника, проверка учётной записи | ответы относятся к этой записи (её репозитории, её профиль, её подписка) | проверка 08.11.2026: одна запись уровня T4, клиент Claude Code (запись проверки — пир-сессия 2026-11-08-10, файлы 00-writer.md и 02-writer.md; передана во входящие РП-560) | владелец РП-560 |
| Учётная запись со входом без подписки: личные материалы, чтение двойника, знания платформы | отказ; отказ; документы пака | живая проверка до перевода — **не выполнена**; код и тест шлюза её не заменяют | владелец РП-560 |
| Адрес Open МИМ | не отвечает — переходное условие остаётся; отвечает — правка обещания | проверка на дату перевода (08.11.2026: адрес не разрешается) | владелец РП-560 |

Перевод в действующее — после выполнения третьей строки и отдельного «да» пилота.
