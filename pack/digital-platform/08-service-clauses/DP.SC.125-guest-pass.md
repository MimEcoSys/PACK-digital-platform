# [DP.SC.125] Реферальные приглашения «Инженерии интеллекта»

## Правило

- У приглашающего одна постоянная ссылка; `/invite` повторно возвращает ту же ссылку.
- Число отправок ссылки и приглашённых заранее не ограничивается.
- Ссылка только фиксирует источник приглашения: она не создаёт подписку, пробный период или временный T2.
- Бесплатные возможности бота и тексты руководств доступны приглашённому бессрочно.
- Функции с ИИ-генерацией, уже закрытые подпиской «Инженерия интеллекта», остаются платными.
- Один аккаунт может быть отнесён только к одному приглашающему; самоприглашение запрещено.
- После первой успешной оплаты приглашённого приглашающему начисляются 3000 бонусов один раз.
- Приглашающий видит агрегированную статистику через `/invites`, без персональных данных приглашённых.

## Обещание

**Держит:** владелец РП-266 (назначено пилотом 14.11.2026).

**Приглашающий:** получает постоянную ссылку через `/invite`, статистику через `/invites`
и 3000 бонусов после первой успешной оплаты приглашённого.

**Приглашённый:** бесплатно регистрируется и пользуется бесплатной частью продукта без
ограничения срока. Пользовательская формулировка обязательна: **«Тексты руководств
останутся доступны навсегда»**.

Реферальная ссылка не обещает доступ к Ленте, персональным инструментам, цифровому
двойнику, личным знаниям, единому поиску, GitHub или другим платным функциям.

## Пользовательский путь

1. Участник вызывает `/invite` и получает постоянную ссылку `?start=invite_<code>`.
2. Бот в этом же сообщении указывает: «Статистика приглашений: /invites».
3. Новый пользователь открывает ссылку и проходит обычную регистрацию.
4. После появления Ory account бот фиксирует пару приглашающий–приглашённый.
5. Бесплатные возможности продолжают работать без даты окончания; уровень доступа не меняется.
6. При первой успешной оплате существующий first-payment-контур начисляет приглашающему 3000 бонусов.
7. `/invites` показывает число учтённых приглашений, первых оплат, начислений и сумму бонусов;
   сообщение заканчивается подсказкой «Пригласить ещё: /invite».

## Свидетельства

| Критерий | Проверка |
|---|---|
| Постоянная ссылка | повторный `/invite` возвращает тот же `referral_link.invite_code` |
| Нет временного доступа | активация пишет только `referral_attribution`; новый `subscription.contract` не появляется |
| Бессрочный бесплатный доступ | бесплатные сервисы не входят в `LOCKED_SERVICES`; `knowledge_*` не требует подписки |
| Платная граница сохранена | закрытые сервисы и Gateway tools продолжают проверять активный `subscription.contract` |
| Однократная атрибуция | UNIQUE `referral_attribution.recipient_account_id` и запрет self-referral |
| Награда | `rewards.applied_events.event_type='referral_attributed'`, `effective=3000` |
| Статистика | `/invites` читает атрибуции, первые оплаты и фактические начисления |

## Реализация

| Компонент | Ответственность |
|---|---|
| aist-bot | `/invite`, `/invites`, deeplink и запись канонического `referral_source` |
| subscription DB | `referral_link`, `referral_attribution`; подписки не выдаёт |
| rewards + projection worker | lifetime guard первой оплаты и фиксированное начисление 3000 бонусов |
| Gateway | бесплатный `knowledge_*`; платные персональные инструменты по активному контракту |

## Ограничения

- Ссылка публична и не является секретом авторизации.
- Платформа не показывает приглашающему имена, контакты или иные персональные данные приглашённых.
- При подтверждённом злоупотреблении конкретная ссылка может быть отключена (`referral_link.active=false`).
- Решение о временном пробном доступе, скидке или другой награде требует отдельного изменения этого обещания.
