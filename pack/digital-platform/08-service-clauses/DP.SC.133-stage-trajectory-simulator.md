# [DP.SC.133] Симулятор траектории Созидателя

> # see DP.SC.133, DP.ROLE.043

## Правило (инвариант)

- Симулятор работает **read-only**: никаких записей в Neon, никаких изменений профиля пилота.
- Pilot-mode **не содержит кодов**: никаких `bh.inv`, `M1`, `slot_logged`, `evidence`, `event_type` в user-facing тексте.
- Ступени называются по именам: «Случайный», «Практикующий», «Систематический», «Дисциплинированный», «Проактивный».
- Нормативы берутся из `stage_config.py` — единственный SoT; симулятор не хардкодит пороги.
- При изменении `STAGE_GATE_MATRIX` симулятор автоматически отражает новые нормы без деплоя UI.

## Обещание

**Кому:** Пилот (Ученик), Навигатор (R27), команда платформы

**Зачем:** После К4-фикса все пилоты wave-1 получили ступень 1, но не понимают почему и что делать. Симулятор переводит абстрактные характеристики в конкретную траекторию: «если делать X — через N недель перейдёшь на ступень Y».

**Что получит:**
- **Pilot-mode:** текущая ступень + главная причина (bottleneck) + одна конкретная рекомендация + график траектории на 12 недель при заданном паттерне поведения
- Ступень считается по порогам, проверенным на данных (не по порогам-гипотезам)
- **Expert-mode:** 7 bh-характеристик × 12 недель + когортная динамика + сравнение сценариев + YAML-загрузка

**Триггер:**
- Пилот открывает Web-приложение или пишет `/simulator` в боте
- Навигатор вставляет ссылку в ответ на «что делать дальше?»
- Команда запускает сценарий калибровки норм (Expert-mode, S4)

**Время отклика:**
- Pilot-mode с реальным профилем: ≤5 сек (включая Neon read + вычисление + render)
- Expert-mode без LLM-парсера: ≤3 сек
- LLM-парсер текстового сценария: ≤8 сек (Haiku + prompt cache)
- Cold start Railway: до 10 сек (принято, допустимо для internal tool)

**Режим отказа:**
- Neon недоступен → показать симуляцию на типовом профиле ступени 1 с пометкой «данные недоступны, используется типовой профиль»
- LLM-парсер недоступен → показать слайдеры вместо текстового поля
- Railway недоступен → CLI-симулятор как fallback для команды

## Свидетельства (критерий приёмки)

**Данные** (что фактически существует):

| Критерий | Как проверить |
|----------|--------------|
| Приложение отвечает на Railway URL | `curl -s https://sim.aisystant.com | grep "Симулятор"` |
| Pilot-mode не содержит технических кодов | grep на вывод: `bh\.` / `M[0-9]` / `slot_logged` → 0 совпадений |
| Write-запрос отклонён | `psql $NEON_SIM_RO_DSN -c "INSERT INTO learning.stage_transitions VALUES(...)"` → `permission denied` |
| Нормативы из stage_config | Изменить STB_GATE[2]=3 → симулятор показывает новый порог без деплоя |
| CONFIG_VERSION в шапке | Вывод содержит строку с версией нормативов |

**Контекст** (при каких условиях):

| Условие | Проверка |
|---------|---------|
| Пилот из wave-1 (есть в Neon) | `SELECT COUNT(*) FROM learning.stage_transitions WHERE account_id=$1` ≥ 1 |
| Сценарий S1 завершён | `scenario_id="s1"` возвращает DataFrame с 12 строками |

**Полномочия:**

| Роль | Что подтверждает |
|------|-----------------|
| Команда (WP-319 владелец) | Smoke-тест Ф7 пройден |
| Верификатор (VR.R.001) | Контракт pilot-mode соответствует эталонному тексту в РП |

**Свидетельства:**

| Свидетельство | Источник |
|--------------|---------|
| Smoke S1: Тсерен видит ступень 1, bottleneck «учебные часы», рекомендацию `/slot 60` | Скриншот / лог Ф7 |
| Smoke S3: 7 wave-1 профилей → все ст.1 | DataFrame из S3 в Expert-mode |
| Read-only: INSERT → permission denied | Лог Railway |

## Пользовательский путь

| # | Шаг | Кто | Сервис |
|---|-----|-----|--------|
| 1 | Пилот открывает URL или пишет `/simulator` | Пилот | TG / Web |
| 2 | Симулятор загружает реальный bh-профиль из Neon | Лаборант | Neon read-only |
| 3 | Запускает S1: траектория ступени на 12 нед при текущем паттерне | Engine | simulator-lab |
| 4 | Pilot-mode: текст по эталону + 1 график | UI | Streamlit |
| 5 | Пилот вводит «а что если учиться 6ч/нед?» | Пилот | — |
| 6 | LLM-парсер → параметры → новая симуляция | Haiku | llm_parser.py |
| 7 | Пилот видит сравнение: текущая траектория vs новая | UI | Plotly |
