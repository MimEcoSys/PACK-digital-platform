# [DP.SC.174] Диспетчер контекста стилей

## Правило (инвариант)
- [x] Диспетчер **вычисляет ключ**, но не хранит данные стиля (данные — у реестра DP.SC.173).
- [x] Корректная классификация канала и роли читателя: детектор канала (A9) различает технический режим и «на пальцах»; мета-класс (человек/агент) + роль определяются из контекста хода.
- [x] **A9 — явная зависимость** (входной артефакт), не скрытая деталь инварианта. При смене реализации A9 контракт Диспетчера не ломается молча.
- [x] Хуки тонкие: логику маршрутизации держит Диспетчер, хук лишь вызывает его.

## Обещание
- **Кому:** рантайм / слой хуков IWE (UserPromptSubmit, PreToolUse).
- **Зачем:** нужная комбинация стилей подбирается автоматически из контекста; хуки не хардкодят правила.
- **Что получит:** вычисленный полный ключ + инъекция фрагмента (от реестра) в промпт.
- **Триггер:** начало хода агента (точка инъекции в системный промпт).
- **Вход:** сырой контекст хода (сообщение пилота, репо, тип артефакта) + A9-детектор как зависимость.
- **Выход:** полный композитный ключ → вызов DP.SC.173 → инъекция результата.
- **Время отклика:** синхронно, **до первого токена** (на этапе хука).
- **Режим отказа:** неоднозначный контекст → дефолтный регистр + пометка о неоднозначности.

## Свидетельства (4 компонента семиозиса)
- **Данные:** правила вычисления ключа (mapping контекст → мета-класс/роль/канал/домен); A9-детектор.
- **Контекст:** начало хода, сработал хук инъекции.
- **Полномочия:** DP.ROLE.074 Диспетчер стилей.
- **Свидетельства:** лог инъекций (какой ключ вычислен); лог пометок о неоднозначном контексте → дефолт.

## Сценарии использования (≥3)
1. **Пилот пишет grep/пути/SHA** — A9 детектирует технический режим → ключ с каналом «технический» → реестр отдаёт плотный регистр.
2. **Пилот спрашивает «объясни на пальцах»** — A9 детектирует разговорный режим → ключ с регистром «на пальцах» (A1-A12).
3. **Синтез стенограммы peer-сессии** — Диспетчер видит жанр «стенограмма хода» → ключ с мета-классом «агент», роль «напарник» → плотный технический стиль без онбординг-замен.
