# [DP.SC.206] Наставник получает сводку о человеке перед ответом

## Обещание

**Кому:** Наставник (человек), который отвечает участникам практикумов и консультационных обращений, в потоках и вне них.

**Зачем:** Без сведений о человеке перед глазами ответ запаздывает и не учитывает прошлое: наставник ищет переписку, заметки, ступень и активность по разным местам. Обещание — убрать этот поиск: наставник называет человека, помощник приносит всё известное.

**Что получит наставник:**
- По нику или имени помощник сам находит человека, без повторных объяснений схемы.
- Одну сводку: переписка и прежние заметки, ступень и квалификация, активность, баллы, чек-лист, прежние потоки и консультации. Что именно входит в сводку, расширяется постепенно, по мере того как владельцы источников подтверждают ключи и доступ.
- Для каждой части — источник и свежесть; если данных нет, об этом прямо сказано, а не выдано за «активности нет».
- Черновик ответа. После утверждения наставником отправленный текст сохраняется заметкой в карточке человека.
- Показ табло: по умолчанию сводка в чате; ссылка на табло потока — по запросу; табло одного человека — только по просьбе (решение пилота 27.10.2026).

**Триггер:** Наставник начинает работу с конкретным человеком (присылает ник, имя или сообщение этого человека).

**Время отклика:** Синхронный ответ в чате (секунды-десятки секунд).

**Режим отказа:**
- Человек не найден или найдено несколько → помощник спрашивает наставника, не угадывает и не склеивает личности.
- Источник недоступен или у наставника нет допуска → в сводке пометка «нет данных / нет допуска» по этой части, остальное показывается.
- Живые данные только допущенному наставнику потока: чужие данные не раскрываются.

## Инварианты

| Правило | Смысл |
|---------|-------|
| **Помощник читает, наставник решает** | Ответ человеку отправляет наставник; автоматической отправки нет. |
| **История одна** | Сводка собирается из сервиса наставничества; копию истории в файлы не делают. |
| **Вывод ИИ отделён от факта** | Каждый вывод помечен как вывод и ссылается на исходный факт. |
| **Дефекты инструмента не чинятся на месте** | Данные чек-листа → РП-522, имена → РП-427, характеристики → РП-151, инструмент → РП-578. |

## Сценарии использования

1. Наставник присылает ник → помощник находит человека, показывает сводку и предлагает ответ.
2. Человек вне практикума (консультация) → сводка по тем источникам, что есть; пробелы названы.
3. Несколько совпадений по имени → вопрос наставнику, кого имеет в виду.
4. Источник чек-листа недоступен → сводка без него, с пометкой.
5. Наставник просит «покажи табло» → ссылка на табло потока; табло одного человека собирается только по просьбе.

## Out-of-scope

- Построение самого инструмента (сервис наставничества, табло) → РП-578; методика практикумов → РП-385.
- Состав характеристик (оси мировоззрения, ИТ-профиля, стиля) → подтверждает владелец РП-151.
