# [DP.SC.211] Проверенный релиз шаблона IWE через Выпускающего

## Обещание

**Кому:** пользователю IWE по шаблону, который обновляется до нового релиза, и автору шаблона, который обкатывает изменение и доставляет его в шаблон (потребность 84, документ 2 — DP.MAP.005).

**Зачем:** пользователь обновляет свою IWE и должен быть уверен, что изменение проверено так же, как любое другое, а при сбое его можно откатить.

**Обещанный исход:**
- Любое изменение шаблона проходит одинаковые проверки; след проверок виден в релизе.
- Что входит в релиз, решает Выпускающий шаблона (Выпускающий российского шаблона — по таблице DP.ARCH.001 «Системы, релизы и Выпускающие»).
- Релиз — помеченная версия шаблона с перечнем изменений; он записывает зависимость «требует перечня инструментов версии M», содержит контрактную спецификацию перечня и условие отката.

**Триггер:** автор передаёт изменение в шаблон; Выпускающий выпускает релиз.

**Время отклика:** по расписанию релизов шаблона.

**Режим отказа:** изменение без пройденных проверок в релиз не попадает; при сбое после обновления пользователь возвращается к предыдущему релизу по условию отката.

## Правило (инвариант)

- Нет следа проверок — нет изменения в релизе.
- Проверяет не автор изменения (DP.SC.171, независимость проверки).

## Как проверить

| Проверка | Ожидаемое |
|---|---|
| Любое изменение из релиза | у него есть след одинаковых проверок |
| Релиз | есть метка, перечень изменений, решение Выпускающего, версия перечня инструментов и условие отката |
| Откат на предыдущий релиз | IWE пользователя работает как до обновления |

## Связь с другими обещаниями

- **Использует:** DP.SC.171 — конвейер разработки с независимой проверкой.
