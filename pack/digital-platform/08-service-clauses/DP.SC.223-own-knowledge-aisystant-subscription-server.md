# [DP.SC.223] Свои знания в ИИ-клиенте через сервер Aisystant с подпиской (мир)

> **Непроверенный черновик.** Сервера Aisystant MCP ещё нет, адрес не назначен, ни один пункт ниже не измерялся. Результаты проверки российского сервера (DP.SC.021, 08.11.2026) сюда не переносятся.

## Обещание

**Кому:** человеку с действующей подпиской Aisystant Corp (мировая аудитория), который добавил сервер Aisystant MCP в свой ИИ-клиент.

**Обещанный исход** (тот же предмет, что DP.SC.021, для мира; не измерялось):
- поиск по личным материалам возвращает документы его подключённых личных источников;
- чтение цифрового двойника возвращает его профиль;
- проверка учётной записи показывает его подписку;
- без входа — отказ; вход без подписки — личные материалы и двойник: отказ.

**Держит:** владелец РП-609 (Aisystant MCP).

**Зависит от:** архитектуры подписки Aisystant Corp (РП-467) — без неё нечем отличить мирового подписчика от гостя.

## Что не входит в обещание

- Подписчики МИМ (Россия) — DP.SC.021.
- Знания без аккаунта — обещание открытого сервера Open Aisystant.
- Удобство и число шагов подключения; запись в цифровой двойник.

**Время отклика:** не задано; назначается при переводе из черновика в действующее.

**Режим отказа:** не задано; назначается при переводе из черновика в действующее.

## Как проверить

Перевод в действующее — только после собственной таблицы проверки на работающем сервере (по образцу DP.SC.021: без входа; с подпиской; вход без подписки) и «да» пилота.
