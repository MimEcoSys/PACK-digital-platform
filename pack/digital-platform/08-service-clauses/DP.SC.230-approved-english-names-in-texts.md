# [DP.SC.230] Утверждённые английские имена в текстах

## Обещание

**Кому:** пользователю IWE и гостю без IWE (потребность 93, DP.MAP.005). Обещание выполняет Переводчик (DP.ROLE.121): у платформы и, по выбору, у IWE.

**Зачем:** английский текст шаблона, своей работы, организации или карточки метода должен называть системные понятия теми же утверждёнными именами. Чужое имя без следа портит общий язык.

**Обещанный исход** (утверждено пилотом 10.11.2026, РП-620 Ф2):
- В англоязычных текстах и материалах платформы системные термины называются утверждёнными английскими именами.
- Если утверждённого имени нет, неутверждённое имя не появляется молча. Имя-кандидат из ручного словаря или имя, выбранное моделью для термина без словаря, допускается только со строкой в отчёте (русский термин, какое имя поставлено, откуда) и в очереди на утверждение пилотом.
- Для карточек Библиотеки методов неутверждённые имена не допускаются: такая карточка не готова.
- Внешнему пользователю открыт снимок только утверждённых имён, и у каждого имени видно, кто и когда его утвердил.
- Область на сегодня: тексты шаблона IWE, свои тексты пользователя IWE, текст гостя по открытому снимку, тексты организаций aisystant и iwesys, карточки Библиотеки методов.
- Запрос смыслового поиска на сервере этим обещанием не переводится. Переводчик отдаёт словарь утверждённых имён в инструкцию ИИ клиента.

**Триггер:** человек переводит текст шаблона, свой текст, текст организации или карточку метода; гость переводит свой текст по открытому снимку.

**Время отклика:** не задано.

**Режим отказа:**
- Утверждённого имени нет, а текст — карточка Библиотеки методов: карточка не готова, неутверждённое имя в неё не попадает.
- Утверждённого имени нет, а текст другой: перевод выходит со строкой отчёта, имя встаёт в очередь на утверждение пилотом.
- Открытый снимок для гостя содержит только утверждённые имена.

## Как проверить

| Проверка | Ожидаемое |
|---|---|
| Текст шаблона с термином из утверждённого словаря | в английском тексте утверждённое имя |
| Термин без утверждённого имени в тексте шаблона, организации или своём тексте | строка отчёта «русский термин → имя, откуда»; то же имя в очереди на утверждение пилотом (ручной словарь кандидатов) |
| Карточка Библиотеки с неутверждённым именем | карточка не готова |
| Карточка Библиотеки только с утверждёнными именами | проверка терминов пустая |
| Открытый снимок для внешнего пользователя | только утверждённые имена, и у каждого видно, кто и когда утвердил. Сегодня отметки «кто и когда» нет: ждёт РП-617 и РП-596 |
| Десять русских запросов смыслового поиска | ИИ клиента пишет утверждённые имена; запрос на сервере Переводчиком не обрабатывается |

## Связь с другими обещаниями

- DP.SC.188 — синхронизация шаблона с английской проекцией. Это соседний конвейер, не исполнение этого обещания.
- DP.SC.029 — английское имя при вводе понятия. Имя живёт в карточке понятия в паке.
- Ц93-02…Ц93-04 уточняют DP.SC.188 и это обещание не закрывают.
